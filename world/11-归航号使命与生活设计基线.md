# 归航号：使命与生活设计基线

2026-09-21 · 用户已接受的使命方向；具体能力、空间与玩法仍待设计和实现。

**归航号是没有可依赖母港的独立文明家园。人们在船上持续生活、认识未知，并选择怎样与宇宙中的他者建立关系。** 本基线替代[07](07-科技纪元与方舟设计依据.md)中“将沉眠社区送达预定地点”的主使命；旧推导保留为历史方案。迁徙可以成为经历或阶段选择，但不据此补造它的建造起源、离港原因与最终目的地。

## 1. 终点成为关于存在的追问

核心设问是：**没有预定归宿时，我们为什么仍愿意继续生活与远行？** 创作弧线从“活下去”走向“值得生活”，再走向“选择如何存在”。意义可以在照管同伴、认识未知、相互托付中形成不同的具体表达，不由宇宙颁发唯一答案。

主题通过经历成立：有人为何愿意苏醒，大家为何选择留下或再出发，一次没有物资收获的探索为何仍值得记住。这些是写作与体验判断，不自动新增意义分数、人物意愿系统或游戏结局。温柔的日常与壮阔的科幻美同时保留；未知不必变成资源或神选使命才有价值。

## 2. 独立、稳定与探索

独立意味着承担维护、生产与决策，不能等待母港补齐一切；它不等于完整工业自给，更不宣告宇宙没有其他人。孤独是当前可靠联系不足的处境，可以被新的关系改变，是否接近也应有选择。

稳定必须有效。可靠供应、可轮休的工作与长期停驻不因玩家做得好便被灾难取消。停留或定居应是正当的生活选择，具体系统与结局尚未设计。继续远行可以为了能力、托付或联系，也可以仅仅因为想知道远方是什么；不能让所有好奇心都必须兑换成收益才成立。

## 3. 休眠服务生活

持续清醒的班底与关系连续性优先。休眠仍可承担保全和必要的长程过渡，但不把正常生活写成两次休眠间的短暂维修班。百年跨星若保留，应是有时间、关系和去留代价的重大选择，不能每到一站就用跳时抹掉共同经历。

七人开局、增加两人至九人的原型事实保留；它们不是整舰容量。苏醒意愿、康复与加入共同生活是待展开的叙事问题，不把现有自动苏醒触发谎称为新机制。原型的紧急休眠、资源、岗位和存档规则均未在本轮修改。

## 4. 手稿必须回答的空间需求

生活空间是持续使用的主要载荷，休眠不再独占总体设计的中心。下表是任务书需求，不是新增舱室已经画完或能够放进旧船体的证明。

| 空间 | 持续承担的生活 | 下一轮手稿要说明 |
| --- | --- | --- |
| 居住与公共空间 | 休息、独处、共餐、讨论与记忆 | 日常动线、安静边界、个人位置和共同使用方式 |
| 医疗与康复 | 照管清醒成员，支持必要的苏醒与恢复 | 与居住、保全、港口之间的转运及隔离关系 |
| 培养与循环 | 食物、水气处理、种源与病害隔离 | 生产与保存的区别、维护入口和物质去向 |
| 工场与储备 | 日常修复、有限制造与知识传承 | 人和设备的工作尺度、备件、工具与检修通道 |
| 港口与探索支持 | 外出、回收、卸料、样本检查与维修 | 双门动线、人员压力边界、伤机及样本交接 |
| 休眠与保全 | 保护沉睡成员与重要记录 | 分区冗余、照管路径；不能挤走清醒生活的全部空间 |

## 5. 候选与制作次序

3400年前后的纪元、0.02c、百年休眠、千人规模、2400米船体及旋转重力继续是候选，须按持续生活的使命复评；日常节奏不能反过来服从旧数字。起源、资源长期循环、清醒人口、去留决策和定居方式仍未确定。

下一步按**生活与探索任务书 → 统一尺度和总体布局 → 港门收纳与旋转/固定接口 → Blender白模**推进。先让各空间与人物、机体一起成立，再验证净空和动作；当前不建模，不替换Unity资产。旧图与原始提示词保留原样，新的空间优先级不能靠修改历史指令伪装成已经画到位。
