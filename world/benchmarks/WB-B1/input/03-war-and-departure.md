# 三、被截断的班期，与第一次归向接应

## 晷川曾经足够好

晷川不是耗尽了所有资源的死地。外侧衡湾经营居住船坞和接驳，内侧铸流承担高规格制造与维护，苇环的培养设施和生物工艺支撑多个居所。它们分别包含分散设施、库存和备份，不是三座建筑被打掉便无人能活。居民有学校、轮班、贸易和私人争执，也有离开这里或一生留下的不同愿望。

航路公署由当地参与通航的共同体设立，承担测绘与接续事务，不是整个远汐的政府。公署组织建造、委托运营**远航号**，用于长期勘测、现场维修、小批加工和先遣保障。船上原有780名随舰居民，包含工作人员及家庭；原先的返港计划会补齐专用耗材和高规格维护。几代家园舰特许让居民的居住权不等于一份可以随时解雇的船员合同。

开场之前，远航号已完成一段消耗较大的外勤，停在晷川外围继续校验。小型先遣此前完成息壤往返，带回相容冰岩样品和外层落点数据。母舰尚未到过那里。剩余物资符合“结束外勤、按期补给”的常规计划，没有为同时失去港口、商运和地区安全预备一场无限远征。

## 入侵为什么会伤及一个本有余力的地方

入侵者是阈庭联政授权的远征军。它试图控制铸流的精密维护体系、取得可持续驻留的工业节点，并以此迫使本地接受不对等的通航和政治条件。这里的工人、设备和成熟工艺比随处可见的石头有价值。它不是为摧毁全人类而来的无限舰队，也不代表所有绮珀人。

远征军预先侦察常规货运、维护接口与守备轮换，在经过测绘的外层空域集结后接近目标。跃迁不能穿过防御直接出现在封闭船坞中。部分打击先于警报抵达远处居民；各地看到的是有传播差的袭击，而非整整80光年同时熄灯。

本地守备立即组织战斗、分散关键设备和转移人员。少数节点被夺，其他节点拒守；攻击、断供、撤离及双方争夺使生产接续失效。侵略者有意保留的产线也可能缺工人、配套件和安全运输。**被打断的是在当前窗口内能够兑现的循环与协作，不是宇宙突然没有原料。** 阈庭并未得到一座按按钮就能开工的完好工业城。

远汐其他社会按收到的消息行动：砧港保护维修能力、组织护航和支援；栖衡接纳一部分伤病与迁离者；逐霜调整培养与运输班期。各方不同意把所有运力交给同一个指挥部，仍能就具体行动协作。专业舰队承担夺回空域、压制敌方和保护交通的主要责任，母舰的到来不会使他们突然学会反击。

阈庭的首批兵力要用于守住既得节点、掩护运输和应对反攻，无法同时监视全部外围。远航号当时不在第一轮重点目标中，依靠位置、原有防护、主动隐蔽与本地掩护保住核心能力。它是当前联络中一艘能够承担长期共同生活的完整家园舰，**不是全星域唯一幸存的船或文明**。有其他军舰、货船、避难居所和民用转运工具继续行动。

砧港也不免于战争，但本版首轮入侵没有夺取它：它在另一恒星系，有本地守备和未失去的工业体系；阈庭暂时无法一边巩固铸流，一边按同样规模打通另一场进攻。砧港承担伤员、来船与自己的居民需求，仍能做分批接待。其安全是受维护的阶段状态，不是剧情赋予的永久免战区。

## 启航选择：不再沿用和平救援的时间表

本版将敌对行动开始记为 **D0**。这是作者共同时间；人物只知道实际收到的那部分消息。下面是一条供主线校核的**标准成功路径**，不是所有存档锁死的逐日剧本。日期是新的叙事选择，不继承旧自然灾害的D29外援、D43靠港或110日结论。

| 时刻 | 已发生什么 | 舰上能够据什么行动 |
|---|---|---|
| D0 | 晷川重点设施遭攻击，守备就地应对 | 远航号仍执行外围作业；没有瞬间获得全系战报 |
| D1 | 第一组电磁警报经过约18小时抵达母舰所在外围空域 | 可确认局部袭击和原班期失效，尚不能声称已知全战局 |
| D2 | 守备联络艇送到更近时的接应安排与部分核实记录 | 母舰收拢外勤、实施减耗，公布有限会合安排；其余失联者另列 |
| D4 | 一艘区域转运艇交接84人，船上增至864人 | 核算全部居民后的存量；艇的压力载荷与航程是作业条件，不是探索机体顺手装84人 |
| D5 | 新报告证实原定补给批次被截留，后备分离段处于争夺中；外围护送承诺仅有效至D7 | 等待仍可能等到转机，但没有在现有安全窗口内兑现的全套补给。求援不停止 |
| D6—D10 | 完成转运艇人员交接；D6在掩护下完成当地撤离机动、校验并进入跃迁，D10抵达息壤外层 | D7到期的是晷川当地撤离保护；需掩护的离开步骤已在D6完成。后续航段及息壤落点由自身先遣与适航条件支持，不把当地保护延伸成全程无风险 |
| D16 | 首批水料通过检查，逐步减少相应净消耗 | 一次样品不等于净供水，营养、滤材、药品仍独立受限 |
| D38 | 合格处理批次与部分消耗品补入成立，有限自给逐渐形成 | 仍需港口高规格维修、药物和工艺服务；不等于建成母港城市 |
| D58—D64 | 下一航程有了合格物资、航路与当期接待凭据，驶往砧港 | 这里的顺利批次和班期可因行动改变；变动后必须重算相关账，不保证照表自动成功 |

作者选择的地方时序同样在走：砧港在D4由一艘早于母舰撤离的守备信使取得首批核实战报；D7决议支援，D12首批护航编队离港，D19到达晷川外围。它不能倒过来成为D6前已经到场的救星，也不能只因船先去了息壤而取消自己的行动。D19后是否守住某个交接点，会影响后来的报告和任务。

### 开场库存与替代方案

为了把“只够一次单程”说清，本版保留 **J** 作为作者配额单位：标准成功路径中，完成满载晷川→息壤这一整个跃迁作业需 **1.00 J**，其中已经包含规定准备与校验消耗；全舰可安全调剂库存共 **1.12 J**，艇载可取余量已算在内。到息壤后余0.12 J，不能再做一次相同航程。按当前载荷和作业计划，直接到砧港的报价为 **2.20 J**，不能由1.12 J完成。它是该航段作者设定的报价，不是一条未经验证的宇宙线性耗能公式。

与工质分开的有水气W、营养N、滤材及工业消耗F、医疗M、常规推进剂P、动力与散热。D4时，按减耗安排和864人需求，最紧的N/F组合保有约60日启动窗口；药物和专门病情仍逐项核对。D38的合格补入发生在该窗口内。任何一条不能因“总资源还有百分之几”自动结清，也不设第61日全舰同时死亡。

| 方案 | 本版事实与不足 | 是否被世界规则禁止 |
|---|---|---|
| 原地等解围 | 护送安排D7到期，新的补给未获确认；敌方可能扩展侦察。继续等是在加大无法补给与无法安全离开的风险 | 不禁止。可以赌，也可能获救；不能当已有接纳承诺 |
| 去砧港或把全舰人转走 | 母舰工质不足；当期运输已分配，联络艇和84人转运艇没有追加承运864人的载荷、住舱和航程余量 | 不禁止未来迁居；此刻没有已就绪全舰转移方案 |
| 小艇买料再带回 | 可以送信和急救品；D6前没有能够交货、装运并安全返回的确认组合 | 不宣称小艇永远无用；以后条件变化必须承认新方案 |
| 在旧域继续生产 | 原料仍在；可用舰载工具、危险空域、原料组合与当前作业时间不能组成已验证补给链 | 不宣布旧域永久不可恢复；本地反击和修复会继续 |
| 去息壤 | 相容样品、无门抵达条件和完整单程库存已经成立；携带整套舰载产线才有持续处理能力 | 有现场放大与意外风险，但不需等待敌方主动放行或尚未兑现的外援 |

因此，启航的必然性是**不能再按失效的回港计划维持这艘船**。息壤是眼下最能由自己实施的完整方案；不伪造“等待必死、所有别人必定拒绝帮助”的宇宙定律。船员公开原因、留下去向和通信方式，并承认没能接到的人。这使后来主动回向晷川有责任和感情上的来处。

## 息壤让船能再走，不替宇宙画句号

息壤是邻系外围行星附近的一小片作业群：冷湾冰卫星的水料，赤脊岩卫星的相容原料与处理试验，帘影环带的观察位置。作者确定这里此前没有文明、遗迹、居民或为主角准备的秘密装置。先遣的真实报告只保证它确曾发现什么，不保证所有批次都一样好。

第一航程让玩家完成外勤、取样、采集与返航，看到公共浴室恢复一段正常开放时间、工场有了可用批次，也看见第一次不为物资的观察。住区、学校和主要生保仍在船上。此处可留下测站、标记和有限物资缓存；本版不把它写成常住千人、功能完备的母港。

未来有人长期开发息壤，在世界里完全可能；首发主线不预定这种结局。母舰前往砧港，是为了它本体的维护、专业供给和居民对外部生活的选择。到了成熟港以后，长期留下也有价值。往后继续远征，必须有愿意同行的人和具体想做的事，不能靠每到一站再制造一场灭顶灾难驱赶玩家。

## 舰长不能以居民身份换取一场胜利

远航号是**大型武装远征家园舰**。它保留防护、港区、工业与机体作业能力，但没有承担舰队主力决战的使命。自卫、掩护回收、应急战斗和撤离会成为有分量的场面；携带家庭去撞开敌方主阵地，不是日常任务。

第一次归向接应安排在砧港修整之后。此时守备与支援舰队已经守住晷川的一处外围交接空域，仍无法保证内侧全面安全。当地需要把一批已抵达集合处、同意离开的居民转交至后方照护。**本地专业队负责进入受威胁地区；远航号负责其真正擅长的接纳、长程生活保障与后续迁送。**

任务成立需要有当期侦察和可信联络、明确护送力量、可实施退路与终止条件、独立留存的回程物资、承载及医护确认。联络失效或敌情越过护卫能力时，集合延期、改由其他承运或撤离，不能用“大家投票愿意冒险”抹去条件。外围只是位置，绝不是安全证明。

### 一条用于验容量的标准接应

以下是成功分支的具体选定演绎，用于避免无限装人；玩家选择改变名单和时刻，必须相应改账。它不要求所有存档迁出同样的人。

1. 砧港修整期间，原864人中有72人自愿安排留居或长期学习，实际住处、生活来源、家庭与照护交接已经落实；他们的回船权利按各自协议处理，不留一份并不存在的双重现住人数。船上余792人。关键岗位得到合格轮换后才准许下一航次，迁走者不因“不可替代”被扣留。
2. 港区支援18名专业人员参加此次承运，分担医疗、对接与现场安全，船上810人。战斗艇的驾驶员若不登母舰，不重复计入舰上床位。
3. 此行明确预约48名接应者，包含需要照护的人。出发前医护评估表覆盖这48人的已知需求；母舰不能治疗的重症另有医疗运输安排。母舰接到全部48人后为858人，低于本次876个生活床位设计上限，余18个生活周转位。它们不是同时存在的18张重症或隔离床。
4. 返抵砧港后，18名支援人员离舰，30名接应者按先前协商入住港区，18名选择继续随舰，船上810人。48人都得到实际接纳与后续安排，不把“18人留船”写成只救出18人。

船数、动力、泊位与医疗能力尚须后续空间和工程设计兑现；这条文字演绎只证明所宣称的人数没有重复使用容量。多来的求救者仍应得到即时援助及转运协调，但不得凭善意把未来长期安置也算作已经完成。

## 归航号：一次完成的承诺

更名发生在这次接应完成、返航人员重新进入生活以后。接回的人里有人马上下船，有人找到了熟悉面孔，也有人得到的只有失联名册上的新日期。母舰没有解放晷川，没能把每个想念的人带回来；专业舰队与地方共同体的功劳有自己的署名。

回程中，居民提出把远航号改名为**归航号**。新接应者也参与讨论；提议不预先作为出征奖励，更不要求任务为了仪式必须成功。完成安置后，经过船上实际的共同议事与登记才生效。可以在提议阶段让反对者说话：有人认为名字像替未归者下结论，有人愿意保留“远航”，也有人理解它是往后接住出发者的责任。正式成功主线选择了更名，但不是全体居民从此没有异议。

旧舰籍、合同、债务、维修履历与家户生活都继续。舰长不能借改名解除责任，也没有一夜换成更大舰体。新的字样可以先出现在港勤通联和餐厅手写牌上，外壳重涂等到正常维护。

“远航”曾是委托给它的一项职业；“归航”成为这批人愿意实践的承诺。下一次为了鹤灯出发时，他们带着能返回的生活和真实关系，也知道不是每个人都要同行。宇宙并未因他们有家而失去吸引力。
