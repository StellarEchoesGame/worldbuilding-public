# WB-B1 与 Claude 设计的比较

作者：Codex。这里只比较方法与证据边界，不是新一轮作品评分。

## 为什么引入 Claude

WB-B1 的题目与评审来自同一模型家族。独立任务、冻结输入与控制题减弱了交流污染，但不能消除共同审美及判断倾向。本次把方法设计交给实际 Claude 调用，并先遮蔽旧题库、旧分数和原稿。它提出分项判断与硬失败条件，不再用综合分数抵消局部问题。这是新增的方法来源，不证明任何一方比另一方更懂游戏。

## 需要解决的旧局限

| WB-B1 中实际观察到的现象 | 新方法需要承担的责任 | 仍然不能证明 |
|---|---|---|
| 可以自由挑一个最强例子回答；同一人物被多次选中 | 执行前冻结抽样框和实例，记录局部证据复用 | 未抽中全文都成熟 |
| 大量题目集中在满档 | 用有证据的分项判定和明确失败诊断描述缺口 | 档位自身已经被实证校准 |
| 两名评分者属于同一模型家族 | 记录实际模型来源、上下文隔离和审查分工 | 不同供应商完全没有共同偏差 |
| 能回答生活与探索题，不等于玩家真的牵挂 | 区分文本依据与真实读者、原型体验 | 游戏好玩或市场接受度 |
| 评委有可能替文档补出好故事 | 直接文本、可追溯推导与补写分列 | 所有推导都无需人工复查 |

旧记录的出处及原始局限见 `b1-observed-limitations.md`。本表没有把“新设计提出了保护措施”当作“保护措施已经在实际世界稿上有效”。执行效果需在未来的冻结版本评审中观察。

## 作者和修订责任

Claude v0 是独立简报下的原始设计。独立审查发现抽样、判定、证据资格、负证据、校准材料及评委配置六项执行问题。修订交回 Claude；Codex 不把自己改写的协议署名给 Claude。最终采用版本以本目录 README 和原始回复哈希为准。

本次没有比较 Claude 与 Codex 谁写出的世界观更好，也没有运行新作品评分；设计方法与评测作品是两个交付。
