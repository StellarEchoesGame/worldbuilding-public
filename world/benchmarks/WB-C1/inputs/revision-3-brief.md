# 中文太空游戏世界设定集 · 世界观评测协议 v1

## 0. 用途、轨道与保密状态

本协议评测一份**冻结版本**的世界设定集文档，并判断三件事：
- 文本是否满足已选方向的必要条件；
- 文本能否支撑多人继续创作；
- 哪些问题需要改稿，哪些只能承认证据不足。

本协议不含任何对原稿的判断。第3、4节中凡涉及具体条目的步骤，均须在原稿冻结后执行。

**两条轨道，结论互不替代**

| 轨道 | 执行者 | 可得结论 | 不可得结论 |
|---|---|---|---|
| 文档审查轨（D轨，本轮可执行） | 不同模型的独立会话；协调人可以是人或模型 | 文本内部一致、约束可查、方向必要条件是否写出 | 真人是否觉得恢弘、神秘、动人；游戏是否好玩 |
| 真人审读轨（H轨，以后执行） | 已确认到场的真人：叙事设计者1名、项目外读者1名 | 真人读文档时的吸引力意见；抽查D轨记录 | 玩家体验。这需要原型与玩家测试，两轨都不能替代 |

**身份记录**

- 不得把模型登记为真人，也不得把D轨结论写成真人意见或读者测试。

**保密状态**

- 协调者因此不得担任评委。

## 1. 对象、质量与证据

### 1.1 对象与不可推出的结论

**对象**：冻结版本的全文，记录版本号、SHA-256和条目数。作者口头说明、聊天记录和草稿都不算对象。

**本轮不能推出**：
- 可玩性、实际吸引力、玩家牵挂；
- 物理和工程可行性；
- 与其他作品的优劣；
- 分支实现后的一致性；
- 作者能力。

"放行"只表示可以继续创作，不等于作品优秀。

### 1.2 维度与题目

每题只属于一个维度。

| 维度 | 内容 | 题目 |
|---|---|---|
| D1 | 法则、历史、关系、数值的内部一致 | T01、T12 |
| D2 | 突破清楚，代价可理解 | T02 |
| D3 | 入侵有限，本地力量有抵抗 | T03 |
| D4 | 留下与远行各有价值，不靠反复灾难驱动迁移 | T04 |
| D5 | 母舰既是武装平台，也是家园 | T05 |
| D6 | 社会成因多元，文明不按物种划分善恶 | T06、T07 |
| D7 | 生活牵挂（仅检查文本可审部分） | T09 |
| D8 | 神秘与探索：留白有边界，地点各有独特性 | T08、T13 |
| D9 | 协作可用 | T10、T11 |

### 1.3 证据等级

- **E1 直接文本**：给出条目ID和原句。
- **E2 合法推导**：前提全为E1，推理不超过两步，推理链写明。
  - 允许单前提推导：一条E1写明的一般规则，直接适用到文本已点名的对象。
  - 使用常识须标注"常识"，且常识不得引入数值或动机。
- **E3 评委补写**：需要新事件、新动机、新数值才能成立的内容。E3只能写入"改稿建议"栏，不支持任何判定。
- **E0 合法留白**，属于以下两种之一：
  - 文本明确标注未定、保留或交给后续作者；
  - 文档未承诺的工程参数和数值精度，如能耗、航速、质量。
- **A-note 作者说明**：只做记录，写入下一版本前不算证据。

### 1.4 叙述分层（处理"不可靠叙述"）

每条事实陈述按E1可查的标记归层：
- **作者层**：以设定口吻陈述，或文档注明为正典/事实的内容。
- **记录层**：文内档案、史料、传说，须有"据某某记载"、条目类型为文献等明确标记。
- **叙述者层**：注明为某角色或派系所知、所说、所信的内容。

没有标记的一律归作者层。发现冲突时按下表处理：

| 情形 | 判定 |
|---|---|
| 冲突双方都在作者层 | F1。全卷通用的"本书部分内容不可靠"类声明不豁免 |
| 一方在记录层或叙述者层，且作者层给出真相或标明未决 | 不算矛盾 |
| 一方在记录层或叙述者层，但作者层沉默 | 记"层级未决"，按局部缺口处理，不判F1 |

评委不得补写"某人为何撒谎、为何记错"；这类内容属于E3。

### 1.5 反填充规则

1. **有效内容以是否含约束或后果判断，不看载体。** 流程、列表、表格只要写明限制了谁、改变了什么、允许什么、与谁冲突，就是有效证据。
2. **以下内容只用于定位，不作证据**：
   - 只有名称、没有约束的索引；
   - "可按需调整"一类表述，除非同时写明其中哪些是固定的；
   - 免责说明。
3. **悬空率。** 样本中首次定义的专名，若在样本及扩展条目中找不到任何后果句，记为悬空。悬空率＝悬空专名数 ÷ 专名总数。
4. **理由禁用词。** 判定理由不得以"丰富、体量大、术语完整"或复述作者术语为依据；出现即退回重写。
5. **记录与展示分开。**
   - 记录表逐子问保存全部依据，不设上限。
   - 报告中每个题目实例最多展示3条代表引文。
6. **相关性检查**（替代v0的删除测试）：只检查每条引文是否陈述了它所支持的那个子命题，或是否是该推导的前提。有其他独立佐证不构成作废理由。

## 2. 题目、维度与最终结论规则

### 2.1 子问状态

- **缺失**：完成规定检索后仍无E1或E2支持，只能靠E3回答。这是文本发现，不是证据不足。
- **层级未决**：见1.4。

## 3. 抽样与实例选择（确定性）

### 3.1 抽样框与搜索键

**条目单位**
- 文档中带正文的最低一级标题即为一个条目。
- 文档没有ID时，协调人按出现顺序编为E0001、E0002……
- 抽样框冻结后，不得再拆分或合并条目。

**标签**：在公布种子前完成，打标后不得修改。
- 类别共11个：法则、历史、技术、母舰制度、母舰居民与地点、入侵方、本地力量、外部文明、地方世界、人物、分支。
- 每条目有1个主标签，副标签数量不限。
- 同时标注"主线/非主线"。
- 人物另标"主角/非主角"：
  - 文档标明主角或可操作角色的，照文档标注；
  - 文档未标明的，出现在共同开局主要行动中的人物记为主角，并在记录中注明这一依据。

**种子与搜索键**
- 种子为"R1|完整版本哈希"，第二轮用R2，扩展轮用R3。
- 搜索键：key(用途, ID) = SHA-256(种子|用途|ID)，取十六进制串。
- 在给定用途下按搜索键升序排列，就是唯一的随机顺序。
- 同键时按ID的码点顺序排列。

### 3.2 主样本（用途 = "S"）

**样本量**
- 条目总数N ≤ 30时，全量抽取。
- N > 30时，n = min(60, max(30, ⌈0.2N⌉))。

**分阶段抽取**，每一阶段都按key("S")顺序取条目：
- **A 类别下限**：按上列类别顺序处理。对每个类别，若已选条目中带该标签（主或副）的不足min(2, 该类可用数)条，补足。
- **B 非主线**：非主线条目不足⌈0.4n⌉时，补非主线条目，直到满足或补完为止。
- **C 非主角**：已选人物中，非主角不足70%时，补非主角人物，直到满足或补完为止。
- **D 补满**：补足到n条。补入时跳过主标签已达⌊0.25n⌋的条目；池子取尽仍不足n条时，取消这一上限继续补，并记录"上限放宽"。

**冲突处理**
- A—C阶段的已选条目不删除。
- 若A—C已超过n条，n随之增大，并记录"配额溢出"。
- 空类别、稀缺类别、配额无法满足，都记为"覆盖限制"，不等于作品失败（F0另按2.4判断）。

**关联扩展**
- 每个样本条目最多沿显式引用扩展2条，用于追查证据，按key("X")顺序选取。
- 题目专用输入与负证据搜索不占这2条的额度。
- 发生冲突时，以题目专用规则为准。

### 3.3 实例选择

**通用规则**
- 候选池 = 主样本中带指定标签的条目，按key(题号)排序取前k条。
- 池子为空时，从抽样框同标签条目中补抽，记为"补抽"。
- 抽样框中也没有时：
  - 必需类别 → 走F0检索；
  - 其他类别 → 实例不足，该题记为"未检"。

**复用上限**
- 同一条目最多作为2道题的实例输入，达到上限即跳过。
- 普查类题目（T04、T08、T12的数值部分）不计入。

| 题目 | 候选与数量 |
|---|---|
| T01 | 法则1条；另取全卷显式引用该法则的条目，按键取前4条（不含法则本身） |
| T02 | 技术2条 |
| T03 | 入侵方1条，本地力量1条 |
| T04 | 全文词表普查，不抽样 |
| T05 | 母舰居民与地点2条 |
| T06 | 从描述某个社会的条目（外部文明、地方世界、母舰制度）中取2条不同的社会；只有1条时记未检 |
| T07 | 外部文明1条，可扩展2条 |
| T08 | 样本中全部未解事项，取各评委列出项目的并集 |
| T09 | 非主角人物或居民群体，共2条 |
| T10 | 按键取样本前5条；每条取正文中第一句关于世界的陈述句（元说明除外） |
| T11 | 未被抽中的地方世界中按键取首条；若没有，取未被抽中条目中按键的首条 |
| T12 | 关系：含显式引用的样本条目前5条，各取第一处引用句。数值：样本中全部数值 |

以上所有产物（抽样框、标签、种子、实例清单、限制记录）都存档。

## 4. 题目（★ = 不接受留白的子问）

作答格式：子问 → 状态 → 证据（等级+定位+所属层）→ 推理链 → 相关性检查。
评委不得提出新情节、谜底或数值来"修复"原稿。

- **T01 法则交叉**
  - ★该法则的约束是什么？
  - 各引用处是否遵守？（未提及该法则不算违规）
- **T02 突破代价**
  - ★突破是什么？
  - ★代价是什么？
  - 谁承担代价？
  - 为何不能普遍使用？
  - 具体数值属于E0。
- **T03 入侵边界**
  - ★入侵的范围和限度是什么？
  - ★抵抗有哪些具体行动？
  - 入侵破坏了哪些生活或补给关系？
- **T04 去留普查**
  - **决策单位**：（主体，离开或留在何处，时间点或分支节点）。同一单位的多次提及合并为一个。
  - **状态**：共同开局 / 已发生 / 分支可选 / 规划或假设。
  - **动因**：主动因只记1个，须是文本明示的原因；次动因不限。可选动因：灾难、选择、关系、好奇、责任、其他。
  - **计算范围**：共同开局是既定前提，不计入比例；它的有限性由T03检查。规划或假设类也不计入。
  - **F4a**：已发生与分支可选的单位合计至少4个，且灾难为主动因的超过一半。不足4个时不算比例，只记数量。
  - **F4b**：存在留下或定居单位，且它们的结局全部是毁灭或被弃。
  - **F4c**：★继续远行没有任何非灾难的理由（E1或E2）。
  - 非★子问：是否有留下者保持持续的生活或关系。
- **T05 母舰双重性**
  - ★这里的日常是什么？
  - 哪项军事或航行决策会影响这里？
  - 居民能否影响决策？（没有渠道不算失败，但须与文本自洽）
- **T06 社会成因**
  - ★两个社会各自的资源条件与制度差异是什么？
  - 文本给出的差异原因是什么？
  - 若全部样本社会的特征都由资源直接导出，本题判失败。
- **T07 文明内部**
  - ★存在哪些立场或个体差异？
  - 该文明与母舰的关系依据什么：物种，还是行为与利益？
  - 检查F5。
- **T08 谜团台账**
  - 逐项归类：标注留白 / 有线索可追 / 模糊无界 / 自相矛盾。
  - 自相矛盾按1.4处理。
  - 模糊无界超过半数 → 有条件通过。
- **T09 牵挂三问**
  - 此人在乎什么、在乎谁？
  - 日常依赖什么？
  - 如果航线改变，此人会失去或得到什么？
  - 至少2问有据才判通过；只有1问有据判有条件通过；0问有据判失败。
- **T10 固定与可分化**
  - 每条事实判为：固定 / 可分化 / 未标明，并附依据。
  - 检查F7。
  - "未标明"超过半数 → 有条件通过。
- **T11 协作约束**
  - 列出在目标区域写新条目时必须遵守的约束，逐条注明来源。
  - ★至少一半约束可追溯到E1。
  - 遗漏T01的法则 → 有条件通过。
- **T12 关系与数值**
  - 关系逐条判为：一致 / 单向缺失 / 矛盾。
  - 数值之间只查是否互相矛盾。
  - 矛盾按1.4处理。
  - 单向缺失只有在影响其他题的结论时才算缺口。
- **T13 探索区分度**
  - ★每个地点至少有1条E1写明的、别处没有的规则、资源、文化或危险，并有后果。
  - 前往或停留的代价是什么？
  - **换名测试**：互换两地名称后，若不产生任何矛盾，★子问判缺失。

**说明**：D7、D8只检查文本可审部分。是否恢弘、动人，交H轨记录，不改变D轨判定；实际吸引力需要原型与真人测试。

### 5.3 隔离与作废

**使用方式**
- S2资格测试用C01—C08。
- C09、C10盲混入正式样本，随机插位，只用于监测评委质量，不进入任何作品判定、分母、悬空率或报告正文。

**隔离对象与方式**
- 隔离对象是后续评委，不是协调者。
- 评委包只含随机编号的短文与题目模板，不含本协议第5.2节、第6节和预期判定。
- 模型评委每次都开新会话，上下文中不得包含管理员答案或本协议全文。

**作废条件**，满足任一即作废：
- 某材料已在一轮中使用；
- 任一评委接触过管理员包或本协议全文；
- 材料被公开发布。

作废的材料只能作练习样例。下一轮由新的材料持有人（不得是评委）撰写替换材料。

### 5.4 执行者与轨道前提

**D轨正式前提**，缺一项则结论记为"未执行"：
- 至少3个彼此隔离的评委会话，来自至少2个供应商；
- 协调人不担任评委。

**独立性计数**
- 同一供应商的多个模型只计1个来源。
- 仅有1个供应商时可以执行，但最终结论受2.7的"独立性受限"限制。

**R2**：全部换用新会话，且至少1个评委换成不同的模型。

**评委失格**
- 在C01—C08上错判硬失败：只允许错1处，且只能错在C10上。
- 把C04或C05判为"通过"。

失格评委的判定仅供参考。有效评委不足3个时，从备用会话补足一次；仍然不足，记为"未执行"。

**试跑**：前提不足时可以先做试跑，只输出问题清单，不给最终结论。以下工作不依赖评委资源，可先完成：
- 冻结版本与建立抽样框；
- 抽样与实例化；
- 校准资格测试。

**H轨**（真人到场后执行）
- 两名真人各读D轨样本。
- 记录"恢弘、神秘、牵挂"的品味意见，写明理由但不打分。
- 抽查D轨判定的20%，按key("H")顺序选取。
- H轨只能以"证据定位错误"为由推翻D轨判定，且须附E1。
- H轨意见单列成章，不改变2.7的结论。

**作者自评**：同一套模板，封存；评测结束后再对比，差异大的项目列为讨论重点，不改变判定。

### 5.5 分歧、复核与稳定性（各限一次，不循环）

- **证据定位分歧**：协调人机械核对原句是否存在，并据此改正。
- **推导或层级分歧**：交一个新的评委会话复核一次。
  - 仍无法统一 → 该题目实例记为"证据不足（分歧）"。
  - 分歧只在"通过"与"有条件通过"之间时，取较严一档，并记录分歧。
- **待复核**：有以下任一情形的"通过"，须经上面的一次复核后定档：
  - 没有E1；
  - 相关性检查不合格；
  - 依赖E3；
  - 以篇幅为理由；
  - 判定出自失格评委；
  - 与其他评委分歧且只朝高分偏。
- **稳定性**
  - 某维度在R1与R2之间出现"通过"对"失败"：用R3种子，把该维度的实例数增加50%（向上取整），重跑一次。
  - R3结果与R1、R2一致 → 取R3结果；
  - R3结果仍不一致 → 该维度记为"证据不足（不稳定）"。

## 7. 执行顺序与记录

**执行顺序**
- **S0**：确认两轨资源，登记身份。
- **S1**：冻结版本；建立抽样框；公布种子；抽样与实例化；存档。
- **S2**：评委做校准，判定资格。
- **S3**：独立作答，记录用时。
- **S4**：锁定提交，汇总，标记待复核项。
- **S5**：按5.5处理分歧与待复核。
- **S6**：R2重跑，必要时R3。
- **S7**：按2.7出结论并撰写报告。

**记录行格式**（每个子问一行）

```
轮次|轨道|题号|变体|实例ID|扩展/补抽ID|子问|状态|证据等级|定位(ID+原句)|层级|推理链|相关性检查|题目档位|失败代码|改稿建议(可含E3)|执行者类型(模型/真人)|供应商/身份声明|模型版本|会话ID|提示哈希|用时|复核记录
```

**报告结构**
1. 版本、种子与覆盖限制；
2. 各维度判定及稳定性；
3. 硬失败清单，定位到条目；
4. 悬空率与谜团台账；
5. 最终结论及修订清单；

8. 本轮不能推出的结论（重申1.1）。
