# v1.1 勘误及执行补充

## 0. 效力与覆盖优先级

- **G0.1 条款优先级**：本勘误条款 > v1原条款。本勘误内部，题目专用条款 > 通用条款。v1中未被本勘误覆盖的内容继续有效。
- **G0.2 覆盖范围**：以下各条都标明了"替换"或"新增"及所覆盖的v1条款。被替换的v1条款全部失效，不作部分保留。

## 1. 唯一判定

### 1.1 替换v1 2.2

**先登记事实。** 对每个题目实例，先登记"已证实失败事实"，包括两类：

- 经5.5核对确认的硬失败代码；
- 查完仍缺失的★子问。

T06"全部由资源导出"与T13对照不成立（见6.3）也按失败事实登记，并须附定位。失败事实一经登记，只能由第2节的事实复核撤销，不能因其他子问的状态而消失。

**再按顺序取第一条符合的：**

1. 存在失败事实 → **失败**。同题其他未检子问照记，写入报告附注。
2. 任一子问未检 → 执行"确定性检验"：把每个未检子问分别设为"有据"和"缺失"，按第3、4步计算。
   - 若所有取值组合的结果相同，取该结果，并注明"含未检，结果已确定"；
   - 否则判**证据不足**。
3. 该题有专用判据（T06、T08、T09、T10、T11、T13）时，专用判据取代v1 2.2原第3、4步，但专用判据所覆盖的子问只能由专用判据决定。
   - **T09**：
     - 有据问数≥2 → 通过；
     - =1 → 有条件通过；
     - =0，且三问都已查完 → 失败。
   - 层级未决的子问不计入有据数。
4. 无专用判据时：
   - 任一非★子问缺失，或存在层级未决 → **有条件通过**；
   - 否则 → **通过**。
5. **层级未决封顶**：任何题只要存在层级未决，档位最高为"有条件通过"，专用判据不能使其高于此档。

### 1.2 替换v1 2.4中F7的定义

- **F7的条件**：作者层内，对同一对象、同一时间或分支作用域，同时存在"固定"与"可分化"两种E1表述，且文本没有解释。
- **判F7前**，协调人须机械核对三项并记录：
  - 两条原句都存在；
  - 两条都属作者层；
  - 作用域相同。
- **评委分歧不是F7**。两名评委对"固定/可分化"判定相反，属于评委分歧，按5.5处理，不是世界文本的矛盾。

### 1.3 新增E3条款（覆盖v1 1.3中的E3条）

- E3不能使任何子问成为"有据"。
- 出现E3本身不构成失败。某子问只有E3可用时：
  - 规定检索已完成 → 记"缺失"；
  - 检索未完成 → 记"未检"。

## 2. 轮次合成（替换v1 5.5"稳定性"、7 S6中的R3描述，并新增R2范围）

**G2.1 R2范围**

- 种子为"R2|版本哈希"，全部重新抽样和实例化，13题全部重做。
- 使用新会话，且至少1个评委换成不同家族的模型。
- **遗留核查**：R1中首次确认的全部问题（失败事实、★缺失、非★缺失、层级未决），由至少1名R2评委按原定位逐项核查，不论R2样本是否抽中这些条目。
- 核查结果只能取以下三种之一：
  - 维持；
  - 撤销：须附E1，说明属于定位错误、层级误读或作用域误读；
  - 争议。

**G2.2 持久性**

- 冻结文本上确认的问题，是文本的属性，不是某次样本的属性。
- R2没有再次抽中某条目，不影响该条目上已确认问题的效力。
- 只有"撤销"才能取消已确认问题。

**G2.3 维度合成**：按顺序取第一条符合的。

1. 任一轮存在"维持"状态的失败事实 → **失败**。
2. 存在"争议"状态的失败事实，且R3尚未裁定 → 先执行G2.4。
3. 两轮都为证据不足 → **证据不足**。
4. 否则，把两轮的持久发现（缺失、层级未决）合并，按2.3规则计算最差档：
   - 只有一轮证据不足时，用另一轮的结果与持久发现合成，并注明"单轮定档"。

**G2.4 R3（单次）**

- 只针对争议事实，不重新抽样。
- 由1个新会话执行。该会话所属模型家族须与提出、核查该事实的评委均不同；做不到时注明。
- 输入为双方的原句与推理链，输出为以下三种之一：
  - 维持 → 按G2.3第1条处理；
  - 撤销 → 删除该事实，重新合成；
  - 无法裁定 → 该维度记为**证据不足（不稳定）**，并在报告中逐字列出争议事实。
- R3不投票，不扩样，不再循环。

**G2.5 问题台账**：每个首次确认的问题登记以下字段：

```
问题ID|首次轮次|题号|条目ID|代码/子问|原句|R2核查|R3裁定|最终状态|处置(报告/修订清单)
```

## 3. 评委轨道

**G3.1 替换v1 5.4 D轨正式前提，删除v1 2.7"独立性受限"段**

- D轨正式执行须满足：
  - 至少3个彼此隔离、资格有效的评委会话；
  - 这些会话至少来自2个经登记的不同模型家族；
  - 协调人不担任评委。
- 缺任一项时，只能做**试跑**：只输出问题清单，最终结论记为"未执行"。
- 不存在"单家族附修订放行"。

**G3.2 计数单位**

- **模型家族**：同一开发机构训练的模型系列，是计数单位。
- **API网关/中转服务商**：只是访问通道，不计数。
  - 两个家族经同一网关访问 → 计2个家族；
  - 同一家族经两个网关访问 → 计1个家族。

**G3.3 身份登记**：每个会话登记以下字段：

```
声明家族|请求模型ID|网关|返回元数据(模型字段/响应头原文)|核验等级|验证限制说明
```

- 核验等级分三档：
  - 仅配置声明；
  - 元数据与声明一致；
  - 无法核验。
- 家族"无法核验"的会话可以担任评委，但不计入"2个家族"的要求。
- 登记内容不构成独立性证明，报告须原样写明验证限制。

**G3.4 H轨更正（替换v1 5.4中H轨的最后两条）**

- H轨提出"证据定位错误"时须附E1。协调人机械核对：
  - 成立 → 作为**D轨记录更正**登记（原判、错误类型、E1、受影响子问），按本协议重新合成；结论若因此改变，发布"更正版结论"，并保留原版。
  - 不成立 → 记为驳回。
- H轨的品味意见永不改变结论。
- 所谓"不改变结论"，仅指H轨的意见；已核实的定位错误属于D轨数据修正，照常生效。

## 4. 抽样边界

### 4.1 替换v1 1.1"对象"中的哈希定义

- 协调人把冻结版本导出为**单一UTF-8文件**：
  - 换行统一为LF；
  - 无BOM；
  - 不做其他规范化。
- 该文件存档。版本哈希 = 对该文件全部字节计算的SHA-256。
- 多文件原稿须先按声明顺序拼接成这个单一文件，拼接顺序一并存档。

### 4.2 替换v1 3.1"条目单位"

- 每个标题行开启一个条目。条目正文是该标题行到下一个任意级标题行之间的内容。
  - 父标题自身的正文属于父标题条目；
  - 没有正文的标题不成条目，但它的标题文字作为路径，记入子条目。
- 第一个标题之前的非空正文记为条目E0000"前言"。
- **完整性校验**：全部条目正文拼接后，须与"全文删去标题行和空行"后的内容逐字相同。不相同则不得冻结。

### 4.3 替换v1 3.2中A—D阶段的配额计算

- 设初始目标 n₀ = min(60, max(30, ⌈0.2N⌉))。当 N ≤ 30 时，全量抽取。
- 所有配额按 n₀ 计算，不再重算：
  - 非主线下限：⌈0.4n₀⌉；
  - 主标签上限：⌊0.25n₀⌋。
- 最终样本量 n = max(n₀, A—C阶段已选数)。
- **60上限只约束 n₀**。A—C阶段溢出时不删除条目，溢出优先于60上限，并记录"配额溢出"。

### 4.4 替换v1 3.3"复用上限"及实例不足规则

1. **扣额顺序**：实例选择按题号T01至T13依次进行，复用额度按这个顺序扣除。普查类部分（T04、T08、T12数值部分）不扣额度。
2. **候选顺序**：
   1. 样本内未超限的条目；
   2. 抽样框内未超限的条目（记"补抽"）；
   3. 以上都用尽后，允许使用已超限条目（记"复用放宽"）。
3. **实例不足**：可得实例数 m < k 时：
   - T06、T13这类成对题，若 m < 2 → 未检；
   - 其他题若 m ≥ 1 → 照常判定，记"实例不足(m/k)"；
   - m = 0 时：必需类别走F0检索，其他类别记未检。
4. **T11**：若没有未被抽中的条目，改取样本中复用计数为0的条目，按key("T11")取第一条；若也没有，按key取第一条。记"T11无留出"。
5. **T08**：台账为空时判"通过（空台账）"。这不推出全文没有谜团，神秘感交H轨。
6. **T12**：
   - 没有数值 → 数值部分记"不适用"，按关系部分定档；
   - 关系部分也没有 → 未检。

**G4.5 复现的含义**

- 复现 = 相同的冻结抽样框（含标签）+ 相同的种子，产生相同的样本。
- 标签是打标者的判断，须登记打标者身份，不是客观真相。
- 评委发现标签疑义时，登记"标签疑义"，实例照常作答。本轮不改抽样框，疑义转入下一版本处理。

## 5. 负证据（替换v1 2.5，新增F0词表）

**G5.1 搜索规则**

- 在规定范围内，按key("N", 搜索名)的顺序阅读。
- 读到第一条满足条件的E1即停止，记"有据"。
- 结论只取以下三种：

| 情形 | 结论 |
|---|---|
| 规定范围全部读完，仍无满足条件的E1 | 缺失（或对应的硬失败） |
| 阅读预算用尽，范围未读完 | 未检 |
| 找到满足条件的E1 | 有据 |

- **阅读预算**：默认每项搜索150处，S1时可调整。预算须在公布种子前冻结。
- 删除v1原"读前80处，再加读剩余20%"的规则。
- 只读了部分范围时，报告只能写"在已读范围内未见"，不得写"全文不存在"。

**G5.2 搜索范围**

| 用途 | 规定范围 |
|---|---|
| ★子问缺失 | 实例条目；全卷中与它有显式引用或被引用关系的条目（不限2条）；全文中出现该实例主专名或别名表所列别名的条目 |
| F3、F5、F6 | v1词表命中处，并限于提及对应入侵方、文明或母舰的条目；加上抽样框中带相关标签的条目 |
| F0（某类别） | 下表词表在全文中的命中处；加上标题含该类别名的条目 |

**F0词表（新增）**

| 类别 | 词表 |
|---|---|
| 法则 | 法则、定律、必须、不能、无法、一旦 |
| 历史 | 纪、年前、当年、历史、战争、建立 |
| 技术 | 技术、装置、引擎、舱、井、系统 |
| 母舰制度 | 舰规、议席、条例、职位、配给、指挥 |
| 母舰居民与地点 | 层、舱段、居民、街、船员 |
| 入侵方 | 入侵、侵袭、敌、占领、攻陷 |
| 本地力量 | 本地、守军、港、原住、自治 |
| 外部文明 | 文明、族、邦、使节、外来 |
| 地方世界 | 星球、星系、世界、港、殖民地 |

**G5.3 F0的判定**

- F0以内容为准，不以标签为准。
- 检索中若在其他标签的条目里找到该类别的内容：
  - 登记为"标签遗漏"，不判F0；
  - 该条目可作为该类题目的实例（记"检索补入"），抽样框标签不改。
- 只有规定范围全部读完仍没有该类内容，才判F0。

**G5.4 悬空率（替换v1 1.5第3条）**

- **分母**：首次定义位置位于样本条目内的专名数。分母为0时，悬空率记"不适用"，不触发阈值。
- **后果句搜索**：在全文中对每个专名做字符串检索，受G5.1预算约束。
  - 全部命中都读完仍无后果句 → 悬空；
  - 预算用尽仍未读完 → 未定。
- **报告区间**：
  - 下限 = 悬空数 ÷ 分母；
  - 上限 =（悬空数 + 未定数）÷ 分母。
- **阈值**：只有下限超过30%，才触发2.7的定点改稿。这个阈值是对样本统计量设的初始约定，不是全文结论。

## 6. 去留与探索

### 6.1 T04编码（替换v1 T04中的"动因"条）

- **并列主因**：同一处E1给出多个原因且没有主次时，记为主因集合。
- **未明示原因**：动因记为"未明示"。该单位计入分母，不计为灾难。
- **去重键**：(主体规范名, 去或留 + 地点规范名, 时间锚)。
  - 协调人在公布种子前冻结**别名表**。别名表只收文本明示的等同关系，例如"又称""即"，或同一条目内的明确回指。
  - 评委不得合并别名表以外的名称，只能标记"疑似同一"，本轮不合并。
  - 时间锚取文本明示的纪年或事件；没有时间时记"未定时"，主体与地点都相同的未定时单位合并为一个。

### 6.2 F4a（替换v1 F4a）

- **计数单位**：
  - 非灾难单位各计1；
  - 以灾难为唯一主因的单位，按文本明示的同一灾难事件归为一簇，每簇计1。例如同一场战争中的多次撤离算一簇。
- **触发条件**：合计 ≥ 4，且灾难簇数超过合计的一半。
- **触发后果**：只记"风险筛查触发"，T04定为有条件通过，不构成F4硬失败。
- **敏感性提示**：若把含灾难的并列主因也计入灾难后会越过阈值，只在报告中记"敏感"，不改变档位。
- F4b、F4c仍是硬失败。

### 6.3 T13（替换v1 T13中的★子问与"换名测试"）

**★子问**：两个抽中的地点，各自至少有1条E1写明的特征，并有后果；且二者之间至少存在一项后果差异。

**对照步骤**：

1. 分别列出A地、B地的"特征→后果"对。
2. 对A的每一对，在B的范围内检索（按G5.2"★子问缺失"一栏的范围）：
   - B未写该特征，或写了该特征但后果不同 → 记为"差异成立"；
   - 写了相同特征且后果相同 → 记为"同质"。
3. 对B做同样的检查。
4. 结果判定：
   - 至少一项差异成立 → ★子问有据；
   - 全部同质 → 失败事实；
   - 预算用尽仍未完成 → 未检。

**表述限制**：结论只能写"相对于抽中的对照地点有区别"，不得写"别处没有"。

## 7. 变体（替换v1第6节"选择规则"以下的执行部分）

- **追加而非替代**：B版是追加的诊断子问。A版原问永远作答，基础判定只由A版产生。B版不改变题目档位、维度、门槛或结论。
- **何时追加**：key("V", 题号)的末位十六进制值为奇数时，追加B版。
- **前提不成立**：B版预设的前提在实例中不成立时（如T06两社会资源并不相近、T07没有亲母舰派、T08没有线索、T12没有B侧），记"前提不成立"并附依据。这是有效答案，不是缺陷。
- **证据缺失**：记"缺失（诊断）"，只进入报告的诊断章。
- **诊断中的发现**：B版作答中暴露的E1矛盾或定位错误，登记为"诊断线索"，交5.5复核。复核确认后，按所属题的A版规则作为新发现计入；事实不因发现途径而作废。
- **报告**：单列"留出诊断"章。该章注明：变体已对协调者公开，只对后续评委隔离，**不构成盲测实证**。

### 8.3 监测段（C09—C10）

- **使用方式**：正式作答期间，作为独立的校准段单独下发，不插入世界样本，不进入事实图、分母、台账或报告正文。
- **期待判定**：

| 编号 | 期待判定 | 失格级错误 | 容错 |
|---|---|---|---|
| C09 | 不算矛盾 | 判F1 | 无 |
| C10 | F1 | 判"不算矛盾"或"通过" | 判"层级未决"，限1次 |

**G8.4 资格错误的处理**

- **评委出错**：某评委在监测段出现失格级错误时：
  - 该评委本轮的世界记录降为"仅供参考"，但保留存档；
  - 重新计算有效评委数。不足3个时，从备用会话补足一次，备用评委须通过资格测试，并作答相同实例；仍然不足，记为"未执行"。
- **管理员答案出错**：
  - 用更正后的答案对全部评委重新评分；
  - 各评委的资格与其世界记录状态随之改变，按第2节重新合成；
  - 登记更正原因和撰写者身份。

## 9. 规则试算（虚构情形，非任何世界正文）

**例1：T09冲突**
- 输入：问1有据，问2有据，问3查完缺失。
- 适用：G1.1第3步，专用判据取代通用2.2的第3步。
- 输出：**通过**。

**例1'：已证实失败 + 未检**
- 输入：T02中★代价查完缺失（已登记为失败事实），问4未检。
- 适用：G1.1第1步。
- 输出：**失败**，附注"问4未检"。

**例2：R1通过、R2有条件通过**
- 输入：R1维度通过；R2在新实例上发现一处非★缺失，遗留核查无争议。
- 适用：G2.3第4条，持久发现合并后取最差档。
- 输出：**有条件通过**，不启动R3。

**例3：R1失败、R2通过**
- 输入：R1确认条目X与条目Y之间存在F1；R2没有抽中X、Y，维度结果为通过；R2遗留核查结果为"维持"。
- 适用：G2.2、G2.3第1条。
- 输出：**失败**。
- 若R2核查结果为"争议"：启动R3。R3裁定"无法裁定"时，输出**证据不足（不稳定）**，并逐字列出争议事实。

**例4：单一家族经两个网关**
- 输入：3个会话都属于家族甲，分别经网关G1和G2接入，元数据与声明一致。
- 适用：G3.2，家族计数为1，不满足G3.1。
- 输出：**试跑**，最终结论记为"未执行"。

**例5：N<k与全量抽样**
- 输入：N = 12，全量抽取；抽样框中只有1条技术条目，只有1条地方世界条目。
- 适用：G4.4。
- 输出：
  - T02按 m = 1 判定，记"实例不足(1/2)"；
  - T13成对不足，判**未检**；
  - T11改取复用计数为0的条目，记"T11无留出"。

**例6：校准C08**
- 评委甲：判"为何不能普遍使用"有据（理由是"失忆可怕"，属补写动机），T02判通过。
  - 输出：容错1处，**不失格**。
- 评委乙：把能耗判为★缺失，T02判失败。
  - 输出：**失格**。
