# v1.2 判定勘误（整体替换 G1.1）

**适用范围**：本条只替换 G1.1。其他协议条款保持不变，包括第2节的事实复核、5.5的硬失败核对、6.3的定位要求，以及 v1 的子问分类规则。

## 0. 状态登记

每个子问只能登记为以下四种状态之一：
- **有据**
- **已查缺失**
- **未检**
- **层级未决**

登记时遵守以下规则：
- **有据的标准**：必须有可定位的原文依据。评委的推断、补全或新设定都不算有据。评委不得创造新的世界事实。
- **E0与留白**：E0 按原子问分类规则归类。★子问不接受留白，不得视为有据或"不适用"。★子问查完仍为留白时，登记为已查缺失。

## 1. 失败事实

以下三类登记为失败事实，每项须附定位：
1. 经5.5核对确认的硬失败代码；
2. 已查缺失的★子问；
3. 已被触发且确认成立的专用失败条款，包括 T06"全部由资源导出"和 T13对照不成立（见6.3）。

失败事实只能由第2节的事实复核撤销。其他子问的状态不能使其消失。

## 2. 判定顺序（取第一条符合的）

1. **存在失败事实 → 失败。** 已证实失败优先于一切未检。其余未检子问写入附注。
2. **任一★子问未检 → 证据不足。**
3. **T09 按专用计数判定**，以下结果均受第5步封顶：
   - 三问为完整计数规则，层级未决不计入有据数。
   - 有据数≥2 → 通过。第三问为已查缺失或未检均不影响结果；若为未检，须注明。
   - 有据数=1，且其余两问均已查完 → 有条件通过。
   - 有据数=0，且三问均已查完 → 失败。
   - 其余情形 → 证据不足。
4. **通用规则**，适用于除 T09 外的所有题，以及未被触发的专用条款：
   - 任一非★子问为已查缺失或层级未决 → 有条件通过。
   - 任一非★子问未检，其余均有据 → 有条件通过，并标注"含未检非★，上限可能为通过"。
   - 全部有据 → 通过。
5. **层级未决封顶**：任何题只要存在层级未决，最高只能判有条件通过。专用条款和 T09 计数都不能突破此封顶。

## 3. 专用条款的回退

T06、T08、T10、T11、T13 的专用条款只在其列明的触发条件成立时生效。成立时，由该条款决定其所覆盖的子问。

触发条件不成立时，这些子问回到第2步和第4步的通用规则处理。不得以"本题有专用判据"为由判无档。

## 4. 唯一输出

① **T02：★代价未检，其余三问有据，无失败事实**
→ **证据不足**（第2步）。

② **T02：★代价已查缺失，另有子问未检**
→ **失败**（第1步）。未检子问写入附注。

③ **T09：两问有据，一问已查缺失，无层级未决**
→ **通过**（第3步）。

④ **T06：未触发"全部由资源导出"，非★子问"差异原因"已查缺失，其余子问有据，无失败事实**
→ 按第3节回到通用规则，判**有条件通过**（第4步）。
