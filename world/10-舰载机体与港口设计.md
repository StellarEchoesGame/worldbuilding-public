# 舰载机体与港口设计

2026-09-21 · 概念提案 v0.1 · 未实现，名称与尺寸均为草图输入

归航号是远征社区的母舰。外出单元承担不同工作，玩家通过它们接触宇宙、保护同伴和带回建设材料。本页延续[工业舰船方向](09-归航号工业舰船方向.md)，将机体与明确的出入港路径一起设计；不代表 Unity 已有机甲、战斗或采集系统。

## 1. 三类原创机体

| 类型与候选名 | 一眼可读的形体 | 擅长与代价 |
| --- | --- | --- |
| **探索型「巡隼」** | 非人形紧凑传感框架；前部传感头、左右可展开姿态臂，下置采样夹。收拢后窄小，展开后形成横向轮廓 | 近距离测绘、信号定位、通道勘察和少量取样；视野与精细操作好，防护及载荷有限，不替代运输与主力采集 |
| **战斗型「守望」** | 约20米级人形装甲机体；宽肩、厚腿、清楚关节，左臂盾、右手常规虚构步枪，背部与四肢有姿态喷口 | 护航、拦截和掩护回收；手臂也可拖带失能同伴。装甲、弹药与维修占用补给，不是探索与采集的万能升级 |
| **采集型「砺石」** | 低重心甲壳状工业躯干；两条粗锚定臂、两条工具臂，作业头前置，可换矿料舱后置，避免人形 | 固定后切割、抓取与装载，能持续处理大块材料；体积大、转向慢，带料时更笨重，需要先勘察作业面 |

三者借用高达系的机械层级与作业感，不复制具体机体、标志或武器外形。战斗型在太空靠姿态控制移动，双腿提供固定与作业姿态，不表现为在真空中跑步。

## 2. 同一艘母舰生产与维护的语言

统一暖灰白外板、蓝灰结构、石墨机械深处与少量砖红识别区。橙黄只标作业警示、抓握位置和接口。大面、承力件、关节三个尺度清楚；磨损集中在夹持、检修及工具接触处。

角色差异先由轮廓成立，再由编号辅助：探索型横向展开、战斗型直立、采集型横宽低矮。收纳状态也保留差异，不能只给同一人形换工具和涂装。

## 3. 共用港口接口

每台机体配置背部或腹部承载鞍座、成对机械锁定点、地面检修接头、牵引救援点及清楚的对接标记。不同体型通过可调夹具和转接托架使用同一套港口系统，不要求外壳尺寸相同。检修接头在固定完成后接入电力、数据与所需补给；矿料舱另有货运转接位。

战斗型约20米高、港口约40米净高仅是这一轮的概念起点。门宽、展开工具包络、夹具行程、通行余量与实际库位容量仍须用体块验证，不能因图中放得下便宣称通过。

## 4. 出击与回收路径

港口位于舰体中段舷侧，设相邻但分开的出击门与回收门；舰外具有可辨认的引导灯和门号。先沿舷侧法向离舰，越过净空边界后再转向目的地，不穿越艉部主推进喷流与禁入区。

**出击：库位 → 检修放行 → 固定/转运缓冲区 → 船外门 → 离舰走廊。** 门外航路清空后释放夹具，机体再启动离舰动作。舰桥给出放行，港口附近不允许自由高速穿行。

**回收：等待点 → 独立接近走廊 → 船外门 → 减速缓冲与固定架 → 检查/卸料 → 检修库位。** 正常返回、带矿返回与被拖回共用这条清楚的流程；失能机体由牵引设施接手。出击和回收的交叉调度由港口状态控制，不靠玩家猜测碰撞边界。

缓冲区用于速度、姿态与夹持交接，不把整座机库当作反复充气的巨型气闸；人员通过局部气闸进入机体。港口画面应同时读出外门、固定架、内部通道和库位，门洞后面不能只是黑贴图。

## 5. 随新手进程逐步开放

第一阶段只开放探索型，完成一次引导出港、调查、回港，奖励实用传感附件与新的可达区域。第二阶段在玩家明确遇到材料需求后修复采集机体，首单矿料直接用于可见设施恢复。战斗型随护航事件再开放，先练习跟随、举盾和安全回收，再引入交战。

锁定机体可在库位中被看见，但不同时呈现完整技能树、配装页和任务列表。每次解锁只新增一项主要操作，并让一次工作产生可见的母舰变化。

## 6. 手稿的可见验收

同页比较三种轮廓与收纳姿态；以战斗机体和人员标出港口尺度；用箭头画清出击、回收及内部转运；保留关闭库位和少量活动灯光，表现尚待恢复的能力。此阶段验收读图与设计关系，随后才验证三维通行、动画与操控。

## 7. 守望：战斗机体手稿约束

**本轮先完成概念手稿，不进入 Blender 建模。** 守望的形象是护航、救援与拦截用的装甲人形；通过护住身体的外甲、可活动的关节和承担机动的设备形成帅气，不靠王冠、神秘水晶或成组装饰翼。约20米仍只是候选包络。

- **头胸：** 低扁、无角的传感头嵌入高领护甲，横向短观察带与头壳分开。胸甲向两侧包覆，中央收束；外肩厚、腰部紧凑，避免把上身堆成一排箱子。
- **四肢：** 肩根、髋根受到遮护，肘窝、膝后留出清楚的活动空间。前臂与胫甲沿肢体包覆，甲片在关节前结束；厚胫、短宽足和可见固定点让它有稳定的重量感，不做礼服式长裙甲。
- **机动：** 背部两具短而厚的推进单元与小腿姿态喷口可辨。左右单元之间保留检修与鞍座接入空间；没有翼状大背包。它们承担护航时的加速与制动，不替代探索型的精密姿态臂或采集型的锚定装置。
- **装备：** 左前臂夹持式工具盾有磨损边缘和抓握/牵引位置；右手持独立机械长枪。盾、武器、背部单元都是可维护设备，轮廓不借用现成名机的标志性组合。武器只作虚构视觉与玩法设定。
- **同一机体：** 正、侧、背视沿用同一头肩、胸腰、膝足与背包关系；左盾右枪不能因视角改变而无说明地互换。拆解页用连线说明外甲、承力骨架、关节及设备的对应位置。

手稿组至少包含完整姿态、正侧背研究、装甲与骨架拆解、背部鞍座/维护接口、收纳与出击姿态。先检查外甲是否遮死关节、推进单元是否挡住固定架，以及装备收拢时的港口关系；这里只评画面可读性，动作与通行仍待后续三维验证。
