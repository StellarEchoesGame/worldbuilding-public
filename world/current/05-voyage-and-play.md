# 五、航程、舰长与玩家的选择

本文定义主线及玩法接口；战争时序、接应窗口和库存采用本版账本，不继承旧自然灾害稿的日期与数值。这里的设计目标不代表游戏功能已经完成。

## 一、玩家带着怎样的家出发

母舰初名**远航号**，是一艘能够长期航行、勘测、现场保障和自卫的大型武装远征家园舰。住舱、学校、医疗、工场与舰载单元共同构成它的远航能力。启航时的864名清醒居民是一次人口截面；后来会有人出生、离世、留下、加入或分段同行，船不会永远装着同一份人员表。

玩家是**舰长**，负责航线、任务编成、舰上资源安排与现场指挥。航务、医疗和作业负责人对各自专业条件承担责任；居民参与长期迁居、公共负担和共同身份的决定。舰长不能用一道命令处置居民的人生，集体表决也不能把不合格的撤离航路或超载接收变成安全方案。

玩家可以切换到外勤专业驾驶员，亲历探索、采集、护送和战斗。角色仍留在各自的物理位置：舰长不必每次亲自离舰，视角切换不意味着意识传送或瞬时跨星遥控。外勤镜头让玩家看见的事，也不自动成为舰长已经收到的情报。

共同循环是：**在船上准备生活与远征 → 在星图上选择航路和任务 → 派出合适的人与载具 → 处理局部现场 → 带回人员、物资、记录和关系后果 → 让船上的生活与下一次选择发生变化。**

## 二、五种玩法服务同一场远航

| 方向 | 玩家作出什么决定 | 回到母舰后留下什么 |
| --- | --- | --- |
| 经营 | 维修与生产排序、储备、岗位、照护、公共空间和改善生活的投入 | 可持续的能力与具体生活变化；不是把所有居民都排进生产线 |
| 战略与战斗 | 在星图上安排航路、编成、补给和与地方舰队的协作；在局部战场中侦察、拦截、掩护、救援或撤回 | 人员与载具状态、弹药与备件消耗、合作承诺和对方会记住的行为；不等于统治整个星域 |
| 探索 | 提出问题、选取观察位置、取样和验证，区分测得的事实与解释 | 新知识、可复用方法、记录及尚未回答的问题；不要求每项发现变成矿产 |
| 固定主线 | 在作者预写的历史、任务与里程碑条件下选择达成方法 | 首发航程的阶段变化、关键人物结果，以及一次有起点和收束的经历 |
| 生成支线 | 回应由地方环境、人物日程和已有关系产生的新机会 | 不同的地方经历、合作与生活变化，所得方法和资源可以改善下一次行动 |

宏观星图处理跨地点部署、航时与接续；局部战场处理同一现场的运动、火力、视线和回收。二者共享人员、载具和消耗，但不把几十光年的地图当成一片可以实时互相开火的战场。具体操作、暂停方式与数值以后由游戏验证。

母舰的武装支持自卫、掩护回收和撤离，因此它不是等待护送的无助箱子。主动突入敌方阵地由适任专艇、战斗机体及地方舰队承担；家园舰留在满足当期保护和撤回条件的区域。威胁越过边界时可以撤退，不能为了出现一场大战，先让全部居民成为不必要的押注。

## 三、从远航号到归航号的主线

固定主线指作者预写共同起点、关键任务与因果条件，不指无论玩家做什么都强制出现同一结局。以下是首发完整成功路线的骨架。

| 阶段 | 当期行动与成立条件 | 阶段结果 |
| --- | --- | --- |
| **原定班期终止** | 晷川遭到有限外域入侵，本地防御实际抵抗。远航号在外勤中保住核心；舰长核对威胁、接应和可行航路，在有限条件下保护已能接收的人 | 家园的原有供应和返港安排被打断；战争发生在真实局部，外部文明和援助能力仍然存在 |
| **息壤的第一次归来** | 抵达先遣已验证的局部作业区。冷湾、赤脊和帘影分别引出供给、作业与观察；相容样品须经过批量验证，产出合格后才进入库存 | 舰上生活改善，形成去砧港所需的下一航程选择；人和主要生活设施继续随船 |
| **星海中还有生活** | 砧港现场修整、检定、补入与转乘。真实可用的居留和服务使安顿成为选择；后续任务须在供货、岗位和照护条件成立后筹备 | 舰长与居民重新获得主动权；有人留下，有人愿意继续经营这艘流动家园 |
| **归向接应** | 获得有时效的求援与接收名单；地方防卫军实际提供有限的保护、通行和撤回条件。专业单元进入危险区域，母舰在受护位置接收、隔离检查与安置 | 接应不是收复整个晷川。成功路线把接到的人与外勤人员带回能够继续生活的地方，并承担后续安置责任 |
| **给这艘船一个新名字** | 接应结果得到核实，居民、船员与新来者经历共同生活和集体讨论后，更名为**归航号** | 名字回应一次实际完成的归来，也成为未来应当兑现的承诺；不靠一条舰长命令或结算奖励自动更名 |
| **自己选择的航线** | 筹备鹤灯多视点科学远征。选择栖衡或逐霜等不同合作路径，确认返航储备；前沿接触人类地方社会及非人共同体 | 远行逐渐由求生走向工作、好奇和愿意共同经历的生活；遇见别人不自动意味着战争 |
| **带着发现与人回来** | 汇合不同位置和光龄的证据，完成当期调查；带回人员和设备，在已约定节点交接、修整、处理履约后果 | 获得一个更可信的宇宙解释和继续远航的能力；首发在已有范围内完成一次真实的自主远征 |

### 一次具体想继续往前的时刻

鹤灯远征的一次值班里，观测屏收到新的红外切片。许照把颜色标尺固定，沿实际航迹移动重建视点：原先像两堵分离墙壁的亮纹，在已测得的片段中显出向深处翻折的关系；缺测处仍然空着。有人一直把它当作两张对不上的漂亮照片，这时第一次认出同一处转折。那片结构横跨许多光年，照亮它的光早在人们出生前就已经出发。

舷窗外大半仍是黑暗。杜禾端着已经凉了的饮料，看着图上的空白问，如果从另一边看过去，那道边还会接在哪里。许照把下一个测点移到图上，说那里能检验他们刚才的猜想。她未必想转行做科学家，却第一次有了一个具体想亲眼知道的答案。下一航段不是从任务栏里凭空长出来的。

息壤没有旧文明遗迹，也不是预先为全舰准备的永久母港。它是新手区和第一处落脚地，不要求采尽矿点、住满一年或分出定居人口才准离开。首发不承诺完整母港定居系统；世界中合理的长期安顿，可以先通过已有港口与人物选择呈现。

归向接应的意义在于这艘船能把一次接回变成持续的接纳。胜利不只发生在武器命中时，还发生在伤员进入医疗、失散者获得可靠消息、孩子找到住处、有人再次有自己的晚饭之后。战斗与日常共同完成更名的分量。

## 四、哪些事实固定，哪些结果交给行动

| 层次 | 必须保持的内容 | 允许改变的内容 |
| --- | --- | --- |
| 共同过去 | 初名远航号；灾前任务与人员过去；入侵及地方抵抗；先遣实际带回的记录；已发生的伤亡和通信 | 不能由支线重骰。新证据可修正人物判断，不可改写已确定的过去 |
| 任务依据 | 息壤原料验证要求；港口真实服务；接应对象、窗口与安全边界；鹤灯既有观测来源 | 不同世界可在尚未被证据约束处形成差异；一旦采用便要持续成立 |
| 达成方式 | 供给、接应、返航和证据质量必须达到各自条件 | 编成、航线、协作对象、侦察方法、资源投入与作业顺序可以不同 |
| 代价与人物 | 人不会被当作可重刷资源；损失、迁居与关系变化需要原因 | 接回哪些人、谁愿同行、谁受伤或离开、信任如何改变，不保证每次相同；关键人物结果须是作者写过的分支 |
| 更名里程碑 | 集体更名属于完成归向接应并承担安置责任的成功路线 | 拒绝、撤回或失败不会随机触发更名，不因击毁足够敌人就跳过条件 |

拒绝参加接应是一个应被世界承认的选择；已接任务也可在条件失效时撤回。接应者和地方部队继续自己的行动，窗口可能过去，人物会回应。不能复活原班人员、重置战况，直到玩家交出规定结局。

没有完成这一里程碑的船仍称远航号。继续探索、停船休整或在安全节点结束本航次，在世界观上都有可能；首发具体可交互分支须据制作范围落实，不能用一条生成支线补发同一场接应和船名。若后来出现新的接应机会，必须有新的事件、信息与能力条件。

## 五、生成支线怎样进入真实世界

生成支线可以由地方环境、作业需求、人物愿望、航期和已有关系形成：一位居民想在下一站团聚，一支队伍需要补做校准，一份失效的交付承诺需要重新谈判，或一处自然现象值得绕行。它们可以帮助主线准备，也可以只让人认识某个地方、保住一次休息或看到此前没有看过的天空。

每项支线在产生时必须明确发起者、真实问题、可用条件、时间窗口与结果。人物有自己的日程，未被选择的事仍会变化。任务不能临时生成恰好补足主线缺口的燃料，不能把尚未确认的人口当成可任意调配的奖励，也不能把遇见的非人居民自动改成敌人。

访问顺序改变获知次序，不改变已经发生的历史。已显示的信号要有相容来源；不能生成相互矛盾的两份过去，再用“其中一份是假消息”补洞。生成内容无权更改入侵性质、核心人物既成经历、更名条件或鹤灯决定性证据的作者答案。

## 六、首发星图与结束的边界

首发保留约40光年跨度、**8个恒星系、2个星际测点、16个重点区域**的内容边界。母舰空间单独计算，背景恒星、未开放港口和远景行星不计为可玩区域。

S0晷川的同一外围区域承载序章与后来的受护接应，按任务和安全条件开放，仍只计1区；其余15区是常规可重访内容，具体状态会随时间变化。受护任务没有把整片灾区变成可自由游览的地图。

S7已有2区中的1区承载独立的**回纹共同体**，另1区保留环境调查职责，不增加恒星系或区域总数。其成员、制度、历史与阈庭联政的关系以文明章节为准；一个共同体不代表整族，入侵军也不代表全部非人社会。

星图必须保留不同合作路线、能够绕行的连接以及重访的意义。安全资料不足、暂时受战事影响、已经知道但本版本未开放，是三个不同状态。不能用一场覆盖全银河的战争掩盖产品边界，也不承诺整颗行星任意登陆。

首发完整成功路线结束时，玩家已经经历求生、经营、受护接应与有价值的探索。修好的船、掌握的方法和建立的关系留下来；有人能替自己的班，有人得到一张新的天空记录。下一次远航源于新的问题与愿望，无须先毁掉这次辛苦获得的生活。
