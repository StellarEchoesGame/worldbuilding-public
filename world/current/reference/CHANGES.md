# 8.1 深化记录

本轮是revision 8的参考条目扩展，主线、时间线及首发容量保持原约定。输出按世界领域组织，避免将世界缩成主角的连续故事。

## 继承

- 稀疏人类通航网、远汐区域、8系2点16区，现有15条重点连接。
- 正航时跃迁、载具传信、有限工业与生态维护；无即时跨星通信、复活或人口休眠库。
- 阈庭有限入侵与本地应对，远航号的家园舰性质、成功接应与共同更名条件。
- D4的864人以及其后标准路径的接应人数；示例不成为所有存档永远相同的名册。
- 息壤无先前文明，鹤灯自然机制，绮珀诸庭／阈庭／回纹的层级关系。

## 本轮具体选定

| 领域 | 补入内容 | 改变的是哪项创作能力 |
|---|---|---|
| 地方档案 | 八系的建成环境、形成理由、生活差异和服务范围 | 写一处地方时，不再只知道它在主线第几章出现 |
| S6/S7 | 分别选择材料分层与温差剥落、颗粒取向与仪器响应差异的自然解释 | 后续任务有作者机制，不靠临时未知填洞；决定性测量另做 |
| 科技接口 | 完整航程、四层制造、跃迁中无外部实时通信/转向/相内战斗、自动系统权限 | 可以检查交通、工业、侦察与日常建议的共同边界 |
| 治理经济 | 三域权责、地方审理与拒绝权、共同供给和私人收入、具签发方的货币和延时清算，以及阈庭非军事生活与权力代价 | 解释一个普通人怎样消费、谋生、迁居或追索损失 |
| 战争外交 | 各方资源、控制范围、互认参加者、战时临时约定、人员保护与执行缺口 | 交战有组织和法律后果，敌友不再只是三种颜色 |
| 生态人生 | 六条物料/能源流程、故障恢复、出生到死亡、无障碍与照护交接 | 社会可以日复一日运行，而不只在任务结算时恢复数值 |
| 文化历史 | 五地五轴、可追溯传统与各自三类立场、艺术媒体及私人信念 | 同一宇宙能容纳不同生活和变化，不复制一种制度口吻 |
| 绮珀细节 | 感觉与过渡接待、幼体六肢雏形和承托需求、亲属与养育分约 | 真实身体影响空间和劳动，同时不替政治作决定 |
| 创作约定 | 核心事实索引、组织与术语、未知类别及三条跨域实例 | 新内容可接入既有世界，已有证据持续约束未访问地点 |

传统的可追溯年代不等于当前国家成立年、舰龄或人类亲眼目击的起点；非人旧记录可以经校准换算为航约纪年。新添习惯是地方选择，不追溯制造一套全舰统一古老教义。

## 保留的具体后续定义

独立舰体尺寸、载具数量、武器性能、生态产率及诊疗参数需工程或专业校核；游戏交互分支需制作验证。它们不作为本轮条目中的可用数值。某位失散者的具体结局、S6/S7决定性数据应在相关任务写作时先选定，不由运行时随机补写过去。

其他文明完整年表、全银河政体与宇宙终极答案仍是创作空间。当前世界并不以这些答案才能运转，也不暗示下个节点必然揭晓它们。

本轮没有改变基线BOOK或既有图稿提示词；Git发布和Wiki部署分别记录，不能由私有Issue交付推断公共站点更新。
