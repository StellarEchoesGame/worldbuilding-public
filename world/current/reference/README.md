# 群星回响 · 世界设定参考集 8.1

这是当前世界设定的主要查阅入口，承接[revision 8总稿](../BOOK.md)已经确定的宇宙、战争开场与母舰主线。这里按照世界的运作方式组织内容；总稿作为概览保留，不用人物按章经历的事情替代世界本身。

也可阅读[八篇合订本](REFERENCE.md)。修改编号源条目后，用 `python3 world/current/reference/assemble_reference.py` 同步合订本与哈希；此脚本只整编文档。

执行与完整交付：[WB-D1 · #31](https://github.com/StellarEchoesGame/worldbuilding/issues/31)。本文所列是创作设定及验证，不表示游戏、图稿或线上Wiki已经实现。

## 版本与来源

基线是#30交付的revision 8，总稿SHA-256 `438c4e31b2e6bd7446d9e162aef4efe89d0154b2446bc28cfbbfff9d954e2898`，本轮不改其字节。8.1补全地方环境、制度、运作过程和文化细节，并将原来待深化的S6/S7自然题目选定作者机制。决定性数据和工程参数仍在使用前验证。

新增内容为制作方在既定方向内选定的作者设定；不是现实发现，也不是声称用户逐项口授。具体后果不因来自某个技能就自动成立，需经过下述交叉检查和独立审读。

[变更记录](CHANGES.md)列新增、继承与仍待深化的内容；[完整性审计](AUDIT.md)逐项对应本轮目标；[内容哈希](hashes.json)固定独立审读版本。审读完成后才交付，不以目录存在或字数达标证明完整。
