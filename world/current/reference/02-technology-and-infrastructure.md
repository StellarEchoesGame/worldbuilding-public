# 科技、基础设施与能力边界

本条目以[宇宙基线](../01-universe.md)为约束。设备的社会后果比一张不断升级的科技树更重要。下面补入作业接口与失效方式，不提供已验算的舰体、武器或产线参数。

## 1. 人工跃迁：能力强，组织成本仍然存在

跃迁把载具送往经校验的稀疏空域，不要求先建目的地星门。每次有正的参考航时，需要合格工质、电力、航务计算、设备状态与后续机动条件。目的地仍在运动，旧坐标必须连同速度和误差解释。

一段航行分为**取得记录—验证载荷与机况—选定抵达空域—准备与进入跃迁—抵达确认—常规机动与交接**。日期和资源按完整过程记录，不把瞬间亮光当全部工作。已有航段也会因载荷改变、天体与设备状态变化而需要复核。

本版选定：跃迁过程中不提供跨星即时通信、外部实时观察、任意转向或相内交战能力。改变目的地需要结束当前航段后重新取得条件。船内生活经历正的时间，人员不因跳跃冻结。技术尚不能取得过去坐标或把后发指令送回较早事件。

跃迁适用于经过测绘的外层空域，不保证紧邻居所、行星或敌舰的跳出精度。小船更容易筹到一次先遣所需载荷与保障，但不能把一艘小信使的航时和费用直接套给满载母舰。材料、检测、储存和失效率会影响同类工质的实际可用量。

**进入生活的后果：**航务公司出售的不是“宇宙通道所有权”，而是测量、责任与服务；富有机构能维持更密的资料更新，小共同体仍可自行调查。事故发生后，争议常在“当时能知道什么”，不是谁持有一张永不失效的地图。

## 2. 机动、能量和看得见的代价

常规推进负责速度匹配、接近、绕行与作业。发动机燃料、反作用推进剂、跃迁工质与电池电量分别管理；不能用一袋矿石同时补足四项。聚变支持长期深空供能，但设备、燃料制备、备用功率和散热决定可以同时开哪些负载。

热控系统把能量搬到散热面排出；高负荷加工、跃迁准备和武器使用会竞争相同的散热与维护能力。关闭休闲照明不等于腾出与重型设备相当的负载，行政节约口号不能代替实际测量。

母舰有分区供能与故障隔离。生活关键负载获得保底，生产线按条件降级；失去一个节点不等于全船黑屏，也不保证全部备份可以无限运行。旋转住区与固定港区通过明确转运连接，消防、失压与货运路线后续要经空间验证。

**可见标记：**工场有高热作业时段，某些走廊旁能看到正在维修的热控部件；岗位知道如何查询自己的真实负载。散热面、传感器和港门在舰体外形上有功能，但本条目不替尚未完成的美术图签工程合格。

## 3. 制造与维修分四层

| 层次 | 远航号可承担的典型工作 | 需要外部接续的部分 | 失败后发生什么 |
|---|---|---|---|
| 通用修复 | 清洁、拆换、结构件、通用管路与已知工艺补修 | 专用检具、特殊材料与合格替件 | 降级运行、隔离故障段，维修履历保留 |
| 受控小批制造 | 已适配配方的工质、部分滤材和普通耗材 | 电极、检测、原料组合与专业签名 | 批次不合格先隔离，不能以平均合格率入生命系统 |
| 精密专业工艺 | 检测、局部调整、有限模块更换 | 高精度光学、先进芯片、大型反应部件及完整药品谱 | 到港或换用真实验证过的降级方案，有性能和生活损失 |
| 工业复制 | 携带图纸、训练资料、安装与调试能力 | 完整产线、冶炼分离、资本/工时、工具母机与供应网络 | 先形成一个可运作工序，再逐步接续；没有整厂一键打印 |

公开图纸、配方许可、当地设备能力与合格检验是四件不同的事。来源合法不保证适配，适配成功也不自动取得独占权。工艺谱系标出材料、机器、过程和检验条件，并记录谁改过；知识可以扩散，制造能力扩展通常更慢。

废件按污染、可修、可拆料与不可安全再用分流。回收物不因叫“资源”就消除了病害、疲劳、混杂元素或性能问题。存放和最终封存都占真正空间，不能把未处理废物从账里抹掉。

## 4. 信息基础设施

同一恒星系的电磁联络仍有传播时间。跨星资料通常由载具带到下一节点，再进入当地网络；定期信使、搭载货运和昂贵专程各有速度、成本与容量。航图、新闻、私人消息和软件更新常常搭乘同一艘船，却有不同公开权限。

签名说明某个密钥为文件负责，不证明内容真实；证书也有过期、撤销消息尚未抵达及被盗用的可能。重要决定同时核对来源、内容、时间、观察条件和实际后果，不以“验证通过”替代判断。

地方网络有缓存和本地服务。远方论坛会出现晚到的回应，连续剧按航次更新，同一作品在两个港的流行期可以错开。个人可选择离线生活；必要医疗与住籍记录不因拒绝商业数据收集而消失。

### 传感与情报

被动观察、主动测量、近处先遣和他人报告相互补充。遮挡、背景、观察方向与设备条件影响置信度；没有一张全域实时雷达。隐蔽是减少被看见、被识别和被持续定位的机会，不是宣称大型热源绝对隐形。

干扰可阻碍某种链路、引入假回波或掩盖辨识条件，但不能自动删除所有纸面记录、独立仪器与见证。对手也要获得作用位置、设备、能源和时间。战争控制的是可观察或可作用的具体条件，不是占了地图图标就能关闭整个星系。

## 5. 自动化、计算与责任

机器人和软件承担重复加工、勘测、危险先遣、物流与诊断。专业人员不是为了让机器永远出错才存在，而是负责设定目的、选择证据、处理不熟悉条件、维护工具及对使用后果负责。相同程序在不同传感、零件与训练条件下不保证同样结果。

自动系统可以有自然语言和稳定的交互个性；本版不把“像人说话”当作已经证明其有主观体验。当前母舰没有被暗中确认成拥有主权的人工人格，人的意识也不能上传换壳。这保留人工心智的讨论空间，不靠突然觉醒的舰载神智解决主线。

任务权限、医疗记录、居民私密和武器控制分开。某个岗位能调用全舰动力不代表能读所有人的私人信件。自动化建议有来源和适用条件；舰长、供应商或委员会不得用“系统要求”逃避自己的决策责任。

**社会张力：**更好的自动检验能释放工时，也可能使原有职业失去议价能力。培训、工作分享、共同服务投入或收入分配是地方制度的选择，技术本身不规定所有失业者必定贫困，也不保证所有人自然富裕。

## 6. 医疗、生物与跨生理接待

人类有成熟创伤治疗、常见慢病管理、修复辅具、康复与有限短期低代谢治疗。药品生产依赖具体工艺与质量链；打印设备不能代替一整套药典。诊疗信息能比医生和药物先到，远程意见仍受信息年龄与现场检查限制。

旋转生活区、身体训练和辅具共同支持长期居住；个体适应差异存在。没有人人永久年轻，也没有通过休眠跳过家庭照护成本的普遍安排。救助首先依据实际需要，参加战斗或科研不是获得基本照护的资格。

绮珀接待使用已知的适配环境、分开的药物与食物链。短时相会可以借助个人调节装置，长期居住要提供完整条件。生物风险按接触材料、来源和检测处理，不以物种或文化身份直接定义“脏”。从未知地点带回的样品需要独立隔离；熟悉的家乡样品也可能出问题。

## 7. 载具如何分工

| 单元 | 世界中的优势 | 不应承担的替代职责 |
|---|---|---|
| 大型武装远征家园舰 | 家庭随行、工作生活接续、维修、样品处理、医疗与长期承载 | 载着全体家户常规突击、复制完整工业文明 |
| 探索单元 | 灵活接近、传感、布设仪器、封存样品与现场取证 | 自动拥有全域情报或所有危险环境适应力 |
| 采集单元 | 锚定、切取、分选、储载及污染控制 | 同时充当满性能战斗机体或无上限货船 |
| 战斗单元 | 按任务进行侦察、拦截、护送、火力和受损回收 | 以个人英雄代替舰队态势、后勤与居民撤回条件 |
| 信使与运输 | 分别优化少量高时效资料与大载荷接续 | 用信使速度证明满载母舰同样可行，或把乘客塞进未改造货舱 |
| 无人设备 | 重复观察、前出测量、危险条件下保存人员 | 无限续航、无工具限制、所有新情况都自主解决 |

机体的动作、损伤和返航结果要能回到维修与人员生活。人形或多肢设计可继承原创美术方向，其任务合理性由实际工具接口与动作证明，不以动画参考自动通过。

## 8. 三条贯穿社会的后果链

**载具跃迁＋有限通信** → 消息、货物和人不同步抵达【能力】 → 库存、服务期限和异地代理变得重要【组织选择】 → 有运力者可以经营更可靠的信用，弱小节点容易被收取高保证成本【分配】 → 互保、商业担保与自营接续形成竞争【政治经济】 → 信件标记发出、到达、已读成为普通常识，承诺措辞更精细【文化】。战争放大差别，和平也不会使它消失。

**生态可循环但设备需维护** → 家园离不开工具、工时与补入【能力】 → 正式照护、培养、维修和备份被纳入共同预算【制度选择】 → 控制关键技术的人拥有议价能力【权力】 → 公开培训与专业拒绝权同时发展，也可能被滥用排斥新人【冲突】 → 修补审美、休息权与对“维持者”的不同评价进入家庭和艺术【文化】。清醒生活不是不断给所有人加班。

**长期跨文明接触＋不同身体** → 接待、翻译和工艺适配成为真实劳动【能力】 → 部分港口建立互认与共同项目【历史选择】 → 适配职业、交易与混合传播媒介出现【经济】 → 独占数据、训练门槛与公共接待投入发生争执【权力】 → 多种身体都可参与的公共空间与对改编作品的不同评价形成【文化】。相同物理约束容许不同社会，也容许明确且无法靠解释消除的敌意。
