# revision 8 修订对照

2026-09-24 · 任务 [#30](https://github.com/StellarEchoesGame/worldbuilding/issues/30)

本轮不再要求新开场衔接旧自然灾害。保留的是仍有价值的世界规则、人物与生活细节；失去前提的情节整段退出当前主线。

## 正式替换

| 旧文或候选 | 本版决定 | 同步影响 |
|---|---|---|
| 晷川遭自然长耀期 | 阈庭联政的有限入侵，本地立即抵抗并持续获得支援 | 自然灾害作者答案、旧近星风险和灾害观察戏不再成立；不写成“外星人制造磁暴” |
| 一开场就叫归航号 | 初名远航号；主动受护接应与后续安置完成，经集体议事改名 | 舰籍与历史连续；旧图名属于制作时代，不能当作开场舰名证据 |
| 非人智慧是否存在完全留白 | 已有确认接触；本版深入绮珀人及一个地方共同体 | 361年接触、401年部分互认，翻译、工业、文化和政治后果进入共同过去 |
| 按族群分友好/中立/敌对 | 阈庭联政侵略；回纹独立，关系按主体、事项、日期 | 同族不等于同国，反侵略不等于无条件同盟 |
| 太空移动要塞的含混印象 | 大型武装远征家园舰 | 自卫与护送有意义，专业力量承担主动突击；家户权利与安全不能由舰长消除 |
| 玩家为远征负责人 | 玩家为舰长；行动镜头可转专业驾驶员 | 舰上值班链延续；镜头切换不发明跨星瞬时遥控 |

| S0仅序章；S7文明未定；14连接 | S0有条件任务重访；S7含回纹；15连接 | 仍8系+2节点、16区；新增处理S0—S2，不增加恒星系 |
| RT-01和平救援D29及D43等 | 重新写D0—D101标准成功路径 | 原结果仅证明其旧假设下方案可行，不为战争版本背书 |

## 保留并重新放置

- 航约428、地球历史连续性、稀疏人类航网与光龄；采用SP-01的1000／500／80／40光年层级，并限定为人类资料与局部范围。
- 正航时、无星门依赖的跃迁，载具传信，工质与电力分账，工艺谱系、有限自动化、循环维护、非万能医疗与旋转居住。
- 息壤此前无文明；冷湾、赤脊、帘影的自然任务；鹤灯自然光回声与尘层折面，不改成战争阴谋。
- 第一批780+84=864人、年龄断面、407家户、18邻里、876生活床位的写作输入。其工程有效性仍待后续概念与模型验证。
- 陶简、许照、杜禾、邵雁及邻里人物的欲望；皱角饼、翻袖外套、借角、留饭签与生活的私密边界。旧日历不直接继承。
- 固定共同底稿、局部可变化；既成记录约束尚未访问的地点，发现只修正认识，不倒改过去。

## 本轮新选定的作者事实

绮珀人及诸庭传统、阈庭联政、回纹共同体、接触年份与两位回纹人物；本地援军D4收报至D19到场的标准时序；成功接应中72人留港、18人支援、48人接回与30人港区安顿的人数演绎。这些是创作方根据已授权方向作出的具体写作选择，不伪称用户逐个口授，也不是外部事实。

## 不把数字冻结成工程结论

1.12 J、一次1.00 J、砧港方向2.20 J、往返5.00 J，以及各段天数是本版作者情境量级。当前验证检查内部引用、因果、时序与数量；没有完成天体模型、产线仿真、舰艇战术或人因工程证明。

若后续工程发现这些量级不可用，须回修整条相关因果，不能只换一个数仍声称原来的等待、生产和撤回方案成立。旧2400米舰长、机体总数及全部编成未在本轮拍板。
