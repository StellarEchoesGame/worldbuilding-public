# 一、一个能远行，却不能同时抵达的宇宙

远航号离开晷川时，原定回港那天要穿的衣服还挂在许多人的门后。航路公署没有消失，保卫家园的舰队也仍在作战；失效的是这艘船能够按班期得到的接应、补给和安全保证。它去往一个先遣到过、母舰从未到过的地方。那里有冰、岩石和可以验证的希望，没有替他们准备好的港口。

《群星回响》描绘的，是**一个被战争迫使离港的共同体，怎样重新取得生活的主动权，并决定值得把家带向怎样的远方。** 生存使第一次启航迫切；与他人的责任使人回望；好奇、事业与相遇，使恢复安稳之后的远行仍然值得。战争有明确责任，不是所有苦难的唯一来源；宇宙也有不需要服务战争的美。

本作延续一个科幻命题：人类能够越过光年，仍不能把彼此带进同一个现在。这个时代也已经遇到非人文明。对方同样有旅行、等待、错判和无法替别人做主的生活。交流可以增进理解，理解不保证利益一致。

## 时代与尺度

故事开始于**航约纪年428年，散居时代**。航约是若干通航社会采用的协定历，不是宇宙历，也不把428解释成公元428。地球与太阳系是可考证的人类来处，仍有人生活；当前故事不发生在太阳系。公元换算本版暂不规定，旧稿约3400年不继续作为定论。

| 层次 | 本版写作基线 | 边界 |
|---|---|---|
| 天文学视野 | 银河及更远河外对象 | 看见的光有年龄，不代表知道当地现在 |
| 本航区保存的可核验实访档案 | 包含个别距太阳约3000光年的远征点位 | 不是全人类航行纪录，也不是连续占领范围 |
| 人类主要常住与常规通航网络 | 最大端点间跨度约1000光年，枝状、稀疏、有空洞 | 不是半径1000光年，更不是所有智慧生命的边界 |
| 本船所处位置 | 距太阳约500光年的边缘分支 | “边缘”指接续密度，不指银河物理边缘或技术一律落后 |
| 远汐星域 | 最大跨度约80光年的地理区域 | 包含多系、多政体，不默认一个政府、一支海军 |
| 首个完整上线版本 | 约40光年跨度，8个恒星系和2个星际测点 | 16个重点区域；母舰空间另计，不承诺全空间连续手飞 |
| 晷川与息壤 | 晷川是远汐中的一个恒星系；息壤是邻系外围行星的卫星—环带作业群 | 息壤不是星域，不等于整颗星球或整个恒星系 |

这些数字是创作范围，不是真实天体目录，也不是经过性能验证的关卡数量。文明已知范围还取决于谁的档案、访问、语言和往来；没有一个所有角色共享的全知地图。

## 四段历史与仍然存在的分歧

**航约之前的早期定居。** 人类先在恒星系内建立人工居所。生态循环可以维护，精密部件却不会自己长出来。跨居所的维修、培养和教学关系先于跨星国家。旧地球语言和历史并未被删除，新的生活方式也不必装成失去来处的古老传统。

**航约0—96，拓航期。** 人工跃迁逐渐成为可重复交通。航约确立统一时序、事故记录和最低接应信号；采用标准不等于加入同一国家。提供船舶和保险的机构拥有很大权力，随行家属常常没有独立于雇佣关系的住籍。

**97—231，接续争议。** 远方产线偏离原厂，通用零件并不总能互换。工人公开检验方法推动互保；错误互换也造成真实事故。公共担保、商业检定和家户轮值从不同经验发展，不是哪一种制度被物理定律选中。

**232年至今，繁支期。** 密集通航和稀疏旁支同时扩展。长途家庭争取“雇佣结束不应自动失去住处”的家园舰特许，地方承认程度不同。361年形成第一份人类与绮珀人的双方可核查接触记录；往来逐步改变贸易和法律，却没有把双方变成统一文明。428年的入侵发生在有历史的政治关系中，不是全人类刚发现宇宙里还有人就立即遭灭绝。

## 三张有日期的图

**光图**记发光时刻、波段与分辨率。**航图**记实际测量过的抵达空域、速度匹配和适用载具。**生活图**记谁能在什么时间提供泊位、医疗、维修和接纳。图上有港，不能推出今天可以靠港；图上没有绘出航线，也不能推出宇宙里有一道无形的墙。

普通电磁信号以有限速度传播。小型跃迁信使可以比同程光更早送到消息，但仍有航行、装载和交接时间。内侧交通繁密的社会可以维持强区域治理；边缘线路低频，权力和信息更容易错开。本作不把分权或误解当成宇宙的强制制度。

## 少数突破，清楚的代价

| 能力 | 可以做到 | 始终保留的代价与限制 |
|---|---|---|
| 人工跃迁 | 不依赖目的地星门；抵达经过校验的稀疏空域；小载具先遣与传信 | 合格工质、电力、准备、冷却、距离和载荷成本。所有跃迁在同一参考时序有正航时，不允许向过去送消息。此为虚构公设，不借现实相对论为它担保 |
| 常规航行与聚变 | 持续深空供能、速度匹配和区域内作业 | 反应部件、燃料、推进剂、散热与动量。电力、跃迁工质、常规推进剂分账；完成跃迁不等于已经停靠 |
| 工质制造 | 常见相容原料经分离、处理、检验成为合格耗材 | 原矿不是成品；产能、过滤介质、电极、检测与维修有限。没有宇宙唯一魔法矿 |
| 自动化 | 熟悉流程的制造、探测、检验和危险先遣 | 信息、工具、训练条件和现场维修有限。机器可以做得更适合的工作，就交给机器；不强迫真人为镜头冒险 |
| 循环生活 | 高回收水气、合格培养食物、种源备份、有限现场补入 | 营养谱、病害、滤材、设备与照护不可省去；水富余不能替代药物，反应堆有电不能打印一切 |
| 医疗与身体 | 创伤治疗、康复、慢病管理和个别短期低代谢治疗 | 无复活、人格转存或百年人口休眠库。年龄、疾病与相聚时间保持人生分量 |
| 住区与港区 | 旋转住区提供长期生活重力，固定区支持港勤和微重力作业 | 转运、压力边界、身体适应和替代通道必须设计；没有任意重力地板 |
| 武装与防护 | 有限防护、拦截、护航、专业作战载具与战区侦察 | 大目标可观测，弹药、散热、维修、情报和训练有限。不存在不可耗竭的全向护盾或按一下便安全的跃迁逃脱 |

舰载机体保留探索、战斗、采集三类职责。人形或多肢构型只有在操纵工具、攀附、回收等具体任务中有解释价值；视觉上可以锋利壮阔，能力上不能把一种机体写成优于所有无人设备和专用船。型号、尺寸、数量和关节设计留到后续概念任务。

“工艺谱系”记录同名零件在哪种设备、材料和检验条件下成立。外来技术同样要接入当地机器与培训；有图纸不等于有工厂，兼容问题也不是永远破解不了的密码。人类与绮珀人使用同一宇宙的物理和跃迁约束，各自在某些工艺上更成熟。

## 回照学与不为战争存在的未知

超光速载具使观察者能选择位置，取得同一天体不同时刻发出的光。这种实践叫回照学。每份样本有光龄、方向和分辨率；恒星光谱与大型结构可以研究，光年之外的一张饭桌不能靠舷窗放大看清。过去的信息不会变成现在的战场直播，也不能从一份旧光谱判定某位亲人今天是否活着。

息壤的冰岩地质、帘影的散射、当地孔隙中的非生物循环，以及鹤灯尘带的局部翻折结构仍有自然作者答案。它们不是入侵者的布置。鹤灯的光回声来自绕经尘埃的旧光；散射回声和受热红外回声分别处理，亮纹移动不等于物质同速移动。

科学发现可以改善某种测量方法，也可以只让人第一次理解一种宇宙结构。没有矿、没有武器、没有任务召唤的地方，仍值得出发。是否存在其他生命形态、银河还有多少文明及宇宙的终极性质继续开放；**非人智慧是否存在**已不再是本版留白。
