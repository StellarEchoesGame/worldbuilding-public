# 群星回响 · 世界观 v1

2026-09-21 · 研究与原创设计交付，已补入 内部参考项目 内部框架参考

**驾着一艘会成长的家园，重新理解那些仍为后来者留灯的地方。**

**现行使命：** 归航号是没有可依赖母港的独立文明家园，持续生活与探索；用户已接受这一方向。没有预定归宿时为何愿意继续存在，由照管、认识未知与相互托付的经历回答。稳定、停留与好奇心都有价值，迁徙只是可能经历或阶段选择。完整依据见[使命与生活设计基线](11-归航号使命与生活设计基线.md)，不据此宣称新玩法已经实现。

这次世界观深化围绕一个核心关系展开：人类曾靠相互照管，把遥远的星空连成可以抵达的航路。许多连接已失效，旧设施仍延续有限的职责。七个刚刚开始生活的人，正好成为了它们等待的“后来者”。

归航号这个名字指向一项朴素的承诺：每次出发，都有人认真准备着你的归来。游戏的成长是这项能力逐渐扩大——从照管一艘船，到有能力为陌生人留下一条去路。

## 本轮设计基线

以下是本轮继续制作的依据，不等于新增内容已经实现或已获用户逐条确认。创作地位、实现状态与揭示范围分开记录。

- **八条世界规则**：物资与维护有代价，休眠与苏醒有责任，航路需要验证，历史呼叫不能冒充实时回应。每条都连接当前玩法。
- **持续生活的文明家园**：清醒班底与关系连续性优先，生活、医疗、工场、培养与公共空间成为持续使用的载荷；休眠不再是唯一中心。意义由经历形成，不设唯一宇宙答案或意义分数。
- **一段有因果的地方史**：潮汐之庭逐渐失去接班，一部分人主动保留公共服务。平台、温室与档案站因此有不同的职责和遗迹证据。
- **一套社会基础**：值守公约，以及工务、种源、记录三类协作体系。它们为舰船和空间站提供不同的功能、材质、标识与生活痕迹。
- **七到九人的完整人物轮廓**：保留岑宁、林芽和闻舟，补全其余同伴的名字、愿望与分歧；开场仍只介绍必要人物。
- **可兑现的谜团结构**：首章回答为何留灯；远方站点的现状需要继续验证。作者知道的答案与玩家已经证实的事实分开记录。
- **八张内容卡与制作约束**：每张写明行为触发、真实收益、新增表现和揭示边界，可以交给剧情、关卡、Blender与界面制作使用。

## 当前阶段：科幻美术、使命与科技共同推导手稿

第一批手稿过度继承旧工程舰轮廓，[07技术提案](07-科技纪元与方舟设计依据.md)曾按休眠迁徙推导人口、重力、动力和工业；该主使命现由[11持续生活基线](11-归航号使命与生活设计基线.md)替代，相关数字需复评。之后的[三种美术探索](08-方舟科幻美术方向.md)因过于跳脱停止深化，当前依高达系舰船参考形成[工业母舰方向](09-归航号工业舰船方向.md)。已有[十页概念手稿](../concepts/mothership/README.md)覆盖双港、舰桥、生活舱和三类机体；它们未自动满足新生活需求。

接下来按生活与探索任务书 → 统一尺度和总体布局 → 港门收纳与旋转/固定接口 → Blender白模推进。保留科幻美与壮阔探索；当前不建模，旧图和原始提示词不因使命调整而改写。

## 手稿之后的场景样板

从断环平台做一段可验证的小样：玩家从远处看见仍亮着的接驳灯，靠近后发现普通货架停用、公共入口却被认真维护；修复接驳，带走有限现货，回到归航号让下一段建设真正发生。随后再发现，温室保存种子、档案站保存航图，也在履行同一种交接习惯。

这段场景可以同时检验飞行、近景美术、环境叙事、经济回报和归航情绪。它应使玩家产生“我想知道下一站留下了什么”的念头。
