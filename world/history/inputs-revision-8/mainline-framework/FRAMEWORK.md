# 群星回响：主线框架提案

版本：v0.2 · 2026-09-23 · 创作提案，尚未替换 revision-7 或公开 Wiki。

输入及旧稿影响见 [INPUTS](INPUTS.md)，审读状态见 [REVIEW](REVIEW.md)。本稿确定一个推荐方向，供下一轮整体修订使用；不把若干互斥方案并排交给用户代写。

## 1. 故事承诺

**一艘失去母港的家园舰，从只能完成一次单程跃迁的幸存者，成长为能够自主远航的流动共同体。玩家带领它从第一片冰原走向有人生活的星海，再驶入尚未被理解的宇宙。**

主线行动：**逃离灾区 → 息壤接续生存与航行 → 抵达通航文明并修整 → 选择一次自己的远征 → 完成发现、带回成果与人 → 决定下一次启航。**

情感主题：失去旧家之后，人们怎样把值得过的生活带向未知。归航号是不断变化的家，群星是值得亲自认识的世界。生存给第一次出发以重量；探索逐渐成为人们能够选择的生活。

revision-7 的“人类能越过光年，仍不能进入同一个现在”继续约束消息、承诺与关系，但不独占全作的情感表达。玩家也应直接感到壮阔、好奇、胜任、期待和获得，而不只学会谨慎。

投入方向：以沉浸探索为主，以成长和人物关系支撑。框架应当回答“下一次想去哪里、去做什么、回来会发生什么变化”，而不仅解释“为什么不能”。

## 2. 整个故事处于怎样的宇宙

采用真实宇宙作为背景：地球属于太阳系，太阳系属于银河系。人工跃迁是本作明确的虚构突破。这里的空间命名统一为：银河系是星系；太阳系及晷川这类单个恒星与其天体系统称恒星系；星域是包含多个恒星系的地理区域；航区按实际通航网络划分，不必与星域边界重合。

本稿推荐的宏观位置：

| 层级 | 主线采用的定位 | 如何进入玩家经验 |
| --- | --- | --- |
| 银河系 | 远大于人类实际居住和通航范围 | 航图拉远后，已知航路仍只占一角；不是整片银河都可当期游玩 |
| 太阳系与早期居住区 | 人类起源及延续至今的社会，有多种政体；不是所有人的现居故乡或必须返回的圣地 | 教材、物品来源、家庭历史及有日期的消息；不先用百科全书讲解 |
| 成熟航区 | 交通、工业和公共服务较密，有长期安顿的真实可能 | 抵达一个确实能够接纳、维修、交换和生活的港口 |
| 边缘航区 | 多个恒星系及少量持续往来的共同体；大片未充分勘测空间夹在航点之间 | 航路疏密、补给方式和消息年龄可比较，不是一条向外越来越落后的等级线 |
| 晷川恒星系 | 归航号居民原有家园和供应网络；局部灾变不等于全人类灭亡 | 回不了的班期、幸存者联络、断掉的维修关系 |
| 息壤作业区 | 邻近边缘恒星系内，一颗外围行星的卫星—环带局部范围 | 冷湾、赤脊、帘影形成首章可理解的近域关系；属概念拓扑，轨道与航时另验 |
| 更远的探索空间 | 可以无人，也可以有先于归航号生活在那里的人；对本舰未知不等于无人拥有 | 观测、现场发现和地方历史分别收紧想象空间 |

保留“散居时代、航约纪年428”为已有相对历。太阳系当代政治地位、对应公历年份、人类疆域直径和星域精确坐标尚未选择；它们不在本稿用未经推导的数字填满。下一轮只补会改变可达性与历史速度的尺度约束，不先绘制全银河国家目录。

地图同时区分**观测范围、可达范围、居住范围**。远处可见的恒星不能自动变成可安全抵达的港口；一张旧航图也不是今天的接待承诺。向成熟航区有真实道路，不能为了迫使探索把它们统统删掉。

主线的相对位置也选定一版：太阳系处于早期散居网络中；沿多段成熟航路可以走向砧港所接续的边缘航区。晷川在砧港的一条低频工业支线上；息壤位于这条支线附近的未开发旁支。归航号先横向避入息壤，再沿可行接续路线去砧港；不需要让整个人类文明都在身后不可返回。“鹤灯”调查区位于这一边缘网络之外，需要经过合作节点再分段部署。栖衡、逐霜是可合作的相邻网络，并非必须打通的两关。这个拓扑只确定方向和网络关系，不把直线距离、每段工质或安全绕行当成已经验证。

## 3. 谁在行动

**推荐玩家身份：归航号的远征负责人。** 玩家组织勘测、资源采集与外勤，提出航线并落实已议定的航程；角色可以驾驶外出单元，也可以调度适合的队伍。最终操作方式不在本稿预设。

航务专业人员负责安全运行；居民参与超出既有约定的长期迁居与远征决定。玩家有决定路线、方法和承担哪些任务的实权，但不是可以把居民当装备的无限船长。重要共同决定需要可见的前因与人物反馈，无须把每个日常动作都做成投票流程。

归航号是群像故事的持续中心。864人暂沿用为开局接应后的人口基线，不保证每个原居民终身随船。居民留居、来访与加入会真实改变船上的关系、劳动与服务安排。人口变化不是删除不赞成冒险的人来提升效率。

## 4. 推荐的六阶段主线

这是一段完整主线的结构，不是制作排期，也不等于六个必须按数字顺序读取的地图关卡。

| 阶段 | 具体目标与行动 | 主要冲突 | 得到什么，为什么继续 |
| --- | --- | --- | --- |
| **序章：回不了的班期** | 外勤中的归航号得知晷川灾变；核对接应、物资与航路，完成有限救援后驶向先遣验证过的息壤 | 多等一个家庭的愿望，与全舰仍能完成接续的条件冲突；救到的人和失联的人都被保留 | 完成真实单程、保护家园核心；到站后原料仍需变成可用供给 |
| **第一章：第一次归来** | 在息壤走通第一次安全外勤，建立补水、原料处理与有限补给，积累下一航段物资 | 样品相容不等于批量容易；载货、人员安全和科学观察需要取舍 | 居民生活改善、船恢复下一航程的选择；下一目标是能够现场大修和重新接入服务的文明节点 |
| **第二章：星海中还有生活** | 推荐抵达砧港这一已知工业节点，完成母舰检查与修整，交换数据、物资和劳动，接到灾区后续消息 | 不同供应者、居民愿望与实际工期；有人想留下，有人想完成本来的勘测事业 | 真正获得安顿与远航两种选择；主线跟随决定继续经营家园舰的共同体，不让一场新灾难取消安顿 |
| **第三章：一条自己选择的航线** | 筹备并启程进行第一次主动远征；推荐科学目标为“鹤灯”旧光在星际尘带中的空间结构调查 | 向未知投入时间和物资，与眼前可兑现的生活改善有竞争；居民无需人人成为科学爱好者 | 选择经过验证的供给节点、准备载具和人员；目标是带回过去从未取得的连续空间证据 |
| **第四章：地图没有说完的世界** | 跨多个测站取得不同方向与光龄的观测，遇见自然危险及地方共同体，修正远征路径 | 远方社会已有自己的日程；另一支作业队的行动可能改变测站可用性，发现与履约不能总同时满足 | 获得真实的新解释、新关系和可再访路线；保留错过的窗口与付出的成本，不把发现简化为稀有矿奖励 |
| **第五章：带着发现归来** | 人员与仪器回到母舰，完成证据汇合、交接和下一轮修整；可在已约定的合作节点结束本航次 | 证据是否足够支持承诺，公开哪些成果，怎样承担协作与缺席的后果 | 第一场自主远征闭合；修好的船、建立的关系、知识和生活都留下。下一航次由新问题与居民选择开启 |

第二章可以出现阶段停留、人员转乘与留居。第五章的“归来”首先是外勤回到船上的生活，也可以包括回到合作港；不要求回息壤，更不要求回地球。

首章结束于恢复并准备执行下一航程，不要求把息壤所有矿点采完、谜题做完，也不要求在此住满一年。教程时长与世界内工期分开：一段维持循环的时间可被叙事略过，不能因此宣称工业生产瞬间完成。

### 首章的具体接力

1. 第一次水样外勤结束，玩家把样品与记录交回归航号；后续批次通过检查并形成净供水后，看见公共浴室恢复一段正常开放时间，认识一个会在下次返航时再见到的人。单筒样品不直接兑换成全舰无限供水。
2. 赤脊任务使小批采集变成持续可用的处理方法。玩家选择保护受损回收余量，运输效率下降，但机体与人员能够回船，新的工具方法保留下来。
3. 帘影提供一次不以物资为目的的观察。它可以早于完整产线恢复；是否追踪精细窗口取决于当时可支配条件，不把“科学必被牺牲”写成唯一正确答案。
4. 航务把下一条实际可行航路、舰体需在港处理的工作及携带储备摆在同一张计划上。居民看到走出去的具体收益。玩家完成出航准备后，息壤留下采样标记、可撤装设备或小型物资缓存；居住与主要生活设施仍随船。

## 5. 为什么是整艘归航号

这里区分三件不同的事：开场必须撤离；离开息壤去文明节点是推荐的集体迁移；修整之后继续远航是选定共同体的主动选择。不能把第一项的必然性偷换成第三项永远没有替代方案。

**从息壤到文明节点。** 归航号的家庭原本就住在船上；息壤没有独立于母舰的完整住宅、学校、医疗和制造网络。下一阶段包括对母舰本体的检查、接口改造和需要港区设备的维修。送去一箱配件不能自动完成所有现场工作。去港还把居民的未来从“维持现状”扩展到迁居、学习、亲友往来和专业服务。保留旧稿多年库存，不新增“特殊零件马上坏掉”的死亡倒计时来催离。

**从文明节点到主动远征。** 归航号继承了勘测、现场加工和长期生活的职业基础。参与者选择把实验室、维修能力及家庭生活带到分散测站附近，减少人员长期两地分离；母舰通常停在经过确认的安全外层，专业载具和无人设备进入风险区域。一次跨多个驻点的远征以数月量级作为叙事目标，正式航时要由路线和保障账验证。

这种选择的收益是连续生活、现场适应和长期作业能力，不是“所有任务都需要真人冒险”。大型保障平台也可能由别的远征船提供；有人可以参加别人的队伍。主线描写为什么这批人选择归航号，不宣称它是全宇宙唯一正确组织方式。

| 反例 | 本稿承认的有效性 | 对主线的实际限制 |
| --- | --- | --- |
| 长期停在息壤，派小艇采购或勘测 | 当航程、载荷与保障条件允许时合理；小范围例行任务优先这样做 | 地理缩小不等于无法定居。主线以可获得的服务、共同体愿望及母舰本体需求支持去港，不宣布驻船必死 |
| 在成熟港长期安顿 | 有效的人生选择；个别居民或一部分家户可留下，也有人后来加入 | 不能把所有港口写成恶意拒收。选择长期定居会结束或改变这支远航主线，而不是自动判为失败 |
| 全部派无人设备 | 熟悉条件、危险先遣和重复测量应当让无人完成 | 自动化的工具、现场维修和样品处理边界要在出发前写清；若无人更合适，就让它完成该段 |
| 把科考队送走，家庭留港 | 合理且确实有人这样选 | 归航号的优势是让长期工作者有携家同行的选择，不是剥夺其他人的安全居留 |

玩家可以在安全阶段暂停推进主线。长远定居是否成为游戏结局、独立模式或后续分支，留待玩法范围确定；当前不承诺一个尚未制作的定居系统。世界观承认它合理，与游戏优先实现远航主线并不冲突。

## 6. 主动探索必须有一件具体想完成的事

推荐首个远征目标：**取得“鹤灯”尘带的多视点观测，解释既有图像里彼此不吻合的明暗结构，并把有限证据能够支持的三维结构带回来。** 这承接 revision-7 已写出的“借光的群山”，将它从第八年后段示范史提升为可能推动一段主线的目标；日期、观测路径与证据首次出现时间需要整体重写。

观测冲突可在文明节点由有日期、方向、波段与误差记录的数据引入。第一章帘影让玩家亲历“看起来不同不等于有一份是假图”，但它不神奇预告鹤灯，也不是另一恒星的隐秘召唤。是否采用同类表现手法，不构成两个自然现象同源的承诺。

作者候选答案沿用已有自然机制：星际尘层的局部翻折与观察几何，使同次恒星辐射在不同路径、时刻被采样。散射回声与受热红外回声分别处理；不会显示死者的近景、未来影像或超光速物质扩张。具体到每个测站的数据和推断，在写决定性证据前定案。

它的回报首先是认识一个原本不理解的宇宙结构，以及亲眼看到它在新的尺度上展开。观测可同时改善某段测站规划，但不要求最终兑换成燃料或武器。别人也可以探索它；归航号可以合作、使用先行者的资料、承认别人的优先发现，未知不专为玩家保存。

给玩家的直观承诺是：**出发时只有两幅对不上的星空；归来时，知道应该从哪里看，才能认出它们其实属于同一片宇宙。** 推荐的发现瞬间是第三组观测抵达后，仪器将受证据约束的尘层片段并列重建，原先相互割裂的亮纹出现连贯的折面；缺测区域仍空着。许照把视点沿真实航迹移动，舰上一个早先看不懂两幅图的人第一次认出了同一处转折。巨大的结构经仪器显现，舷窗外仍是它在当前波段和视角下的样子。接下来的一次观测可以验证推断，也可以推翻部分模型；这个场面不许诺一键看穿整片星云。

这不是全宇宙终极谜底，也不是晷川灾难幕后阴谋。晷川仍按自然灾变处理，回照调查与寻亲有各自的证据边界。主线通过阶段性发现形成前进动力，后续可以换成生命、恒星、天体结构或不同社会的问题，不把所有遭遇接到一个反派上。

## 7. 人物让路线成为自己的选择

| 人物 | 真正想去做的事 | 与主线发生的矛盾 | 可以看见的改变 |
| --- | --- | --- | --- |
| 陶简 | 得到故乡失散者的后续线索，仍想演一次喜剧 | 私人回望与大家需要修整、远征的安排不同步 | 能把寻亲与公共航程分开；演戏不再等所有问题解决，既有失信也不被一场演出抹去 |
| 许照 | 完成一次属于自己也愿与别人共享的宇宙观测 | 害怕错过窗口，容易把他人的生活也当作品素材 | 镜头和判断变得可靠，仍保留表达欲和出发的兴奋，而不是成长为只会提醒限制的人 |
| 杜禾 | 有自己的晚上，穿喜欢的衣服去一座陌生城市，看一次别人的演出 | 远征不断借用公共善意，承诺的私人生活易被挤掉 | 她能拒绝一项额外任务，也能主动选择下一站；新衣服不必都为劳动服务 |
| 邵雁 | 找伴侣的去向，重新获得专业身份，也能有人替自己的班 | 一边盼同行者可靠，一边不愿失去不可替代的位置 | 有学徒能够接手后，她第一次可以为自己的事离舰，不靠伤病才被允许休息 |

温芮、林澈、陈颂等生活人物保留。孩子期待新的天空或朋友，使远航有人情味；孩子的愿望不替全舰授权风险。人物可能改变想法，也可以只参加某一段旅程，不能每个人都在结尾统一说“我要去群星”。

## 8. 三个技能怎样实际约束本稿

### 8.1 中文审查：偏离、场景和谜团

核心突破只取已有的人工跃迁公设；成熟聚变、自动化和循环生命保障属于有代价的未来能力，不新增万能能源、复活或即时跨星通讯。本次不因技能要求而增加第二、第三条物理奇迹。

每一项核心设定都有场景作用：信息年龄限制救援判断；现场制造能力决定息壤任务；居住随船使去港变成集体迁移；无人能力改变任务方法；远征成果回到同一群人的生活。开场先让玩家知道“我在一艘有人生活的船上，原定回港失效，眼下要完成接应与撤离”，地理百科后置。

需要明确作者答案的是长耀期性质、先遣样品真假、已出现观测的来源，以及当期科学谜团；非人智能、银河其他文明与宇宙终极性质继续留白。本稿不会用早期线索暗示即将解答尚未准备的宇宙秘密。

### 8.2 系统推演：三条后果链

箭头中的关系区分物理约束、制度选择与角色反应；一种环境允许多种社会，不把后果表当历史必然律。

1. **载具有代价的跃迁 → 航行与运货不会因消息早到而同时完成 → 各地保留产线和库存 → 港口服务与可靠往来有价值 → 家园舰失去旧供应关系后要建立新关系 → 居民为不同航线争论 → 玩家决定哪段行程值得投入。** 前两层是能力约束；供应组织和最后选择可以不同。
2. **循环生命保障仍需维护与补入 → 家不能只是一间睡舱 → 舰载培养、工场与照护共同支持长期外勤 → 职业和家庭可以随船 → 有人愿意保留流动生活，有人更重视固定居所 → 港口成为真实分流处 → 主线共同体的选择获得意义。** 家庭随船是历史与制度的一种结果，不是物质循环自然产生统一价值观。
3. **光带着过去的信息、载具能更快改变位置 → 可以比较不同光龄与视角 → 新证据能修正旧解释 → 观测需要路线、校准与协作 → 远征与地方其他活动发生取舍 → 发现有作者以外的利益相关者 → 带回成果改变知识与关系。** 收益可以纯粹是认识，不自动带来可采资源。

### 8.3 循环文化：家的利益也进入远征决定

只采用本技能的五轴提问方法，不把“分子混合产生身份”“体内物质比例决定公民权”当科学事实或本作制度。归航号继承灾前生活，不在灾后几个月凭空长出多代古老教义。

| 检查轴 | 本稿采用的方向 | 会发生的具体冲突 |
| --- | --- | --- |
| 共同生活如何理解循环 | 务实地维护水气、食物与设备，同时允许不同私人理解 | 新食物够营养但缺熟悉味道，保留风味试验要占真实空间 |
| 时间与加入 | 权利按社会安排和实际接纳生效，不按“换过多少身体物质”分级 | 新来者资历待核，基本生活仍受保护；工作信任逐步建立 |
| 内外边界 | 样品、污染作业与居住分流；人员文化身份不等于污染等级 | 好奇者想提前看样品，设备和服务有不同通道 |
| 死亡与纪念 | 未知去向、确认死亡、私人纪念分开；不预设身体归还义务 | 航线可能错过纪念或团聚，承诺需要兑现或道歉 |
| 决策与权力 | 专业安全责任和居民长期生活决定相互约束 | 探索派、安居派和务实中间者均有合理利益，也能改主意 |

这些关系通过返航后的饭、维修后的浴室、错过的约会与新结识的人表达。主线高潮不能每次都是开会批准一张预算。

## 9. 可以生成什么，什么不能交给局部生成重写

- **共同骨架：**灾前有家、灾变打断供应、一次可靠单程、息壤局部接续、外部人类文明仍在、母舰可逐步恢复自主航行。阶段功能应连续，不保证所有存档每个居民都有相同人生。
- **本稿的推荐作者选择：**砧港作为第一处修整节点，鹤灯作为第一场主动远征目标。用户采纳并修订正典后才能成为该版本固定内容；目前不是随机生成器接口。
- **允许变化的地方内容：**兼容原料的具体分布、可行的作业方法、旁支路线、人物谈判与地方社会的不同历史选择。变化必须兑现此前出现的信号、航次与资源约束。
- **行动造成的变化：**谁加入、合作关系、错过的窗口、公开哪些资料、取得的知识和维护能力。地方社会按自身事件时间变化，不等玩家抵达才行动。
- **不能重骰：**已经发生的灾害、接应、观测来源、已知人物的过去，以及同一世界内既成的事实。访问顺序改变认识，不改过去。
