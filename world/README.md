# 群星回响 · 世界观

当前入口是 [**世界设定参考集 8.1**](current/reference/README.md)，在revision 8共同底稿上补全空间、社会、技术与生活细节。执行与完整交付见 [WB-D1 · #31](https://github.com/StellarEchoesGame/worldbuilding/issues/31)。

**一艘被战争迫使离港的家园舰，先让生活延续，再主动接回他人，最后带着自己选择的使命驶向未知。**

按问题查阅[世界设定条目](current/reference/README.md)，需要先了解主线时读[revision 8总稿](current/BOOK.md)。[当前版本入口](current/README.md)区分二者。线上 Wiki 已于 2026-09-25 按本版同步（[#35](https://github.com/StellarEchoesGame/worldbuilding/issues/35)）；游戏尚未采用新版。

## 这版的共同底稿

- 航约428，远汐星域是稀疏人类航网边缘的一片区域；已有少量非人接触。
- 晷川遭阈庭联政有限入侵，本地抵抗与外部支援持续发生。
- 母舰初名远航号，载有持续生活的共同体，玩家为舰长；它是大型武装远征家园舰。
- 息壤是一处局部新手作业群，不是完整星域或预定母港。
- 自愿受护接应、实际安置和共同议事完成后，更名归航号；主动远征还有科学、事业和相遇的价值。
- 首发写作范围为8个恒星系、2个星际测点、16个重点区域，母舰另计。
