这一页检查“各张图是否仍是同一艘船”。主轮廓、港口、舰桥和推进器的位置必须能互相对应，表面的机械细节才有继续深化的基础。

## 外形六视图

<ArtFigure image="/art/current/02-exterior-views.png" alt="归航号左舷、右舷、顶部、底部、舰艏与舰艉六视图概念" />

*左舷双港与右舷连续外壳形成明确区别；艉部为两列、每列三层的六喷口组合。*

| 观察位置 | 应保持的身份 |
| --- | --- |
| 左舷 | 前出击、后回收的相邻双港，中间有结构隔离梁 |
| 右舷 | 连续的载荷外壳，不自动镜像出另一组双港 |
| 顶部与底部 | 主舰身长轴、前肩与后动力段对应，尾部呈两列推进器的可见投影 |
| 舰艏 | 短而厚实的折面轮廓，主色块连续 |
| 舰艉 | 六喷口按两列三层布置，中部保留结构与设备空间 |

初稿曾在俯视和底视画出三列推进器，与艉视冲突。当前页已改为两列；这是部件数量关系的修正，不代表已经完成精确投影验算。

## 壳板拆解与功能剖面

<ArtFigure image="/art/current/03-systems-exploded.png" alt="归航号外壳概念爆炸图及保全、居住、双港、工业、动力和推进分区剖面" />

*拆解图说明外护壳与内部结构的层次。下方剖面应理解为“上层居住、下层双港”；底部居住标签与机库括号仍有轻度排版歧义，以此说明为准。*

从舰艏向舰艉，当前功能关系依次为前向防护、社区保全、中段居住与港口、工业、动力、推进。它们是供美术与空间设计讨论的候选分区，不是已完成容量计算的工程布局。

保全区应体现分区隔离和长期照管；港区需要容纳真实的进出、固定、卸料和维修流程。后段动力与推进在形体上集中，避免把所有复杂设备平均铺满船身。

拆解图的虚线用于回指部件所属区域。外壳可以拆开画，并不意味着已经证明工具能进入、部件能够运出，或结构能按这个顺序安全维护。

## 本轮修正与下一步

剖面初稿多出第三个机库口，推进总成标签也误指向游离壳板。当前版本已恢复前后双港，并将引线接回艉部推进总成；双港在中段的位置可与主视和侧视对应。

下一步需要一张统一标尺关系页，把全舰、港区外凹槽、内部通行口、机体和人员放在同一套尺度里。旋转居住段的支承、交通与压力接口，还要同固定港区一起推敲。当前六视图可指导后续概念手稿，尚不能直接作为建模尺寸依据。
