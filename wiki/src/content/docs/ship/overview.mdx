> 这艘船在世界中的使命与生活，见[归航号 · 移动的家园](/world/ark/)；本页记录它的视觉设计。


归航号是一艘承载社区的远征母舰。它要有清楚的航行方向、足够厚重的生活与保全空间，也要有让外出机体认得出的归港入口。玩家靠近时，应先看见一艘船，再发现里面仍在继续的生活。

**状态：当前工作方向，概念手稿阶段。** 本页展示原创设计研究，尚未作为正式定稿；这套设计尚未完成 Blender 建模，也没有替换 Unity 运行资产。

## 一艘可以回家的工业母舰

当前方向从高达系舰船的体块组织中提炼工业感：连续的长轴、短而厚实的折面舰艏、受保护的小型舰桥，以及明确成组的艉部推进器。它保留承载社区所需的体量，也让机库、检修与机体活动成为外观的一部分。

左舷中段的双港是主要识别点。前港负责出击，后港负责回收；两者共享母舰的维护体系，各自保留独立入口。门洞需要有厚度、内部通道和固定设施，不能只是一块黑色贴图。

这艘船的情绪来自“正在恢复的生活”：少量亮着灯的工作区、关闭的库位、修补过的部件，以及逐渐重新启用的公共空间。成长会改变船上的活动，而不只是增加外壳装饰。

## 共同的制造语言

| 层次 | 当前设计取向 |
| --- | --- |
| 大体量 | 连续主舰身、厚实前肩、内收港区、集中的后动力段 |
| 色彩 | 暖灰白外板、蓝灰结构、石墨色机械深处；砖红用于少量识别区 |
| 细节 | 大面留白，港口、接缝与检修处集中机械细节 |
| 灯光 | 琥珀色强调操作与锁定位置，居住光带表现生活尺度 |
| 使用痕迹 | 磨损集中在夹持、检修和接触处，补焊与换件保留年代差异 |

同一套语言延伸到舰桥、餐舱和三类机体。它们不必外形相同，但应让人相信来自同一套制造与维修体系。

## 使命更新后的设计重心

归航号的使命已转为持续生活与探索的文明家园。下一轮总体手稿需要让医疗、工场、培养区、公共空间与休眠保全共同支撑船上的生活，检验空间如何连接、谁会使用、哪些变化来自建设。当前图稿形成于这次使命修订之前，仍保留原始图像和完整提示词；新使命没有自动解决尺度与机构问题。

## 当前已收敛与仍待解决

跨页评阅已确认主轮廓、色块、左舷双港、紧凑舰桥与六喷口的主要身份关系。早期侧视漏画港口、发动机数量不一致等问题已经返修，过程见[退回方案与返修记录](/process/archive/)。

**统一尺度仍未通过。** 全舰、机体、人物与港口局部还没有放入同一张可靠标尺页；公里级舰体与约二十米级机体只是探索中的设计输入。后续必须把这些关系画清，再进入三维空间与动作验证。
