> 港口的世界背景见[归航号](/world/ark/)及[科技与能力边界](/world/technology/)；本页记录机构与作业空间的手稿。


归航号的左舷设置相邻而独立的出击港与回收港。它们既是玩家离开与返回母舰的入口，也是探索、战斗和采集机体共同使用的维护设施。

**状态：流程与部件意图可读，门片真侧剖及统一尺度仍待解决。** 本页是概念设计，不表示港口动画、碰撞或机体通行已经在游戏中实现。

## 从舰内看向宇宙

<ArtFigure image="/art/current/04-hangar-design.png" alt="归航号双港机库内景、出击与回收布局、门框及捕获架拆解" />

*主景将出击与回收分开，平面关系图补充内部转运。右侧研究门框、导向机构、捕获鞍座与服务接头。*

机库首先需要让人理解自己在哪里：门外是宇宙，门内是固定架、轨道与服务设施；港口之后还有可去的库位，不能到门洞就结束空间。

机体背部或腹部的承载鞍座与托架相接，成对锁点承担固定，检修接头在机械固定完成后才接入。不同机体通过夹具和转接架使用共同接口，不要求外壳长成同一种形状。

## 一次出击与一次回收

| 流程 | 设计中的动作顺序 |
| --- | --- |
| 出击 | 库位 → 检修放行 → 待放行位置 → 托架送至门口 → 外部航路清空 → 解除固定并离舰 |
| 回收 | 舰外等待 → 独立接近走廊 → 门内减速与捕获 → 机械锁定 → 检查／卸料 → 转运至维修库位 |
| 异常返回 | 牵引或拖带进入回收侧，固定后转入隔离与维修区，避免堵住正常出击线 |

离舰后先沿舷侧向外取得净空，再转向目的地。回收走廊与艉部推进喷流分开；两条航路和内部横向转运均需要调度，不能把平面上相交的轨道当成可同时自由通行。

*补充页增加 HOLD A／B、横向转运车、卸料区与隔离维修区。门片候选为垂直上提，收纳在舰壳内部的上方空间。*

图上的三种门态说明运动意图，但它们仍主要是正面透视。**尽管图中文字写有“侧剖”，这一页还没有真正剖开门片与收纳腔。** 刚性门叶的终位、驱动机构以及它们与上层舱室的互斥空间，仍须用真侧剖补清，不能靠“收进船壳”一句话带过。

人物与机体的比例也尚未统一。局部修订改善了重型机体的体量感，但门内人物、转运细节和全舰视图之间仍有差异；不能从现图直接量取门宽、门高和拖带包络。

## 真空区与人的位置

机库按低重力、真空作业区研究。托架和轨道负责搬运，港内人员穿压力服并使用系留；普通人员停留在局部加压服务盒内，通过小气闸或密封通道进入工作位置。整座巨型机库不会为了每次出击反复充气。

这些边界应在后续图中继续保持：压力窗后的人、开放机库中的压力服人员和无人设备，各自有明确位置。它们也是将来的动画、音效与新手引导可以依赖的空间信息。
