## 本轮的设计决定

**使命更新：** 用户已接受[独立文明家园与持续生活](../../world/11-归航号使命与生活设计基线.md)的方向。归航号没有可依赖母港，生活、探索与关系共同形成存在的意义；迁徙不是预设终点。十页图保留原样作为现有概念，生活、医疗、培养、工场和公共空间仍需按新使命补任务书，休眠不再是唯一主载荷。接受使命不等于图稿或尺寸定稿。

归航号是一艘承载生活的厚重远征母舰。短折面舰艏、收束的中段港区、紧凑舰桥和成组艉驱建立长轴轮廓。暖灰白外板、蓝灰结构、石墨机械与少量砖红识别块，贯穿舰体、内景和外出机体。

左舷中段有前出击、后回收两个独立开口，内部连到固定、检查和转运设施。右舷保留封闭维护面。艉部主喷口为两列、每列三层。生活在保护壳内，活动区域的暖光和封存区域的安静共同表现尚待恢复的社区。

探索型「巡隼」、战斗型「守望」、采集型「砺石」沿用同一套材料、检修与夹持语言，但各有轮廓与工作方式。名称仍为候选。

## 后续收敛顺序

执行顺序以[完整制作路线图](../../world/12-后续制作路线图.md)为准：先一次交齐总体方案，再并行推进全舰空间与作业，汇成完整概念审定包后进入对应白模验证。原有图面待办纳入整包处理。

先用持续生活与探索任务书回答“这是一艘什么样的家园”，再评阅轮廓、色块并收敛尺度。当前2400米母舰、20米守望、10—12米作业机体与港口净空仍是[候选输入](design-spec.json)，**尚未统一映射到各张手稿，也未按新使命完成容量复评**；不能直接据图建造正式模型。

下一轮先补生活与探索任务书，再画统一比例尺的舰体—舱室—外侧服务凹槽—内部通行口—机体—人员总体关系，随后解决真实门片收纳侧剖、旋转居住段和固定交通接口。然后才用Blender白模验证同模视图、净空和运动，最后细化资产与Unity接入。当前不开始新建模。
