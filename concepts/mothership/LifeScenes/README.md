## 设计状态

- 本轮工作假设为**数百人共同生活、七位首章主要人物**。这是新的设计候选，七位不是全舰人口；准确数量、容量和年龄结构尚未确定。
- 暂将三景放在同一候选旋转居住段的稳定重力环境内。没有确定旋转半径、2400米船体或转换机构，不画无依据的星景落地窗。
- Unity仍保留既有七人开局原型；本批不修改人口、休眠、家庭、轮班或生产机制，不以图像宣布它们已经实装。
- 培养区表现生活与生产关系，不证明食物预算或生态闭环；餐厅也不承担全舰总容量证明。

## 评审与继续制作

先评生活动作、邻接关系、私密与卫生边界、共同风格及人机尺度，再列出真正需要改画的地方。邻里容量、后场物流、医疗可达性和空间总量随后进入统一任务书与总体手稿；旋转/固定接口及通行白模仍在后续阶段，当前不建模。

旧[母舰概念册](../README.md)和历史图像保留原样。本目录的候选不自动替换旧模型或成为最终舰内布局。

## 实际交付与评审

每张图由一个主景和两处细节研究组成。[完整提示词与参考图链](prompts.json)记录内置 image_gen 的实际输入；[逐图评审](review.md)记录图面所见和剩余问题。培养区的[返修前图](03-cultivation-commons-v1.png)保留，用于对照主景入口与卫生缓冲小图的调整。

- 餐厅：分桌就餐、取餐队列与回收凹位可读；脏盘后场流线及具体交班动作仍待深化。
- 街廊：缝补、搬送、阅读与门前停留可读；楼梯净宽、无障碍与疏散待统一平剖验证。
- 培养区：主景入口已关闭，配套轴测表达公共门、转折缓冲与培养门。轴测公共门上部随墙剖去，并非半高门；下一轮需补全门高与剖切线。
