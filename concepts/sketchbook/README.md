## 后续画什么

下一批优先画人物工作服与使用姿态、归航号的餐桌和轮休空间，以及放大的接驳/交接界面。室内须先补明确的重力工况和舱段尺度；人物先探索衣装、携物与动作，不将第一张随机脸当成定稿。

这些设计逐步回答“这个文明怎样生活”。再据选定的结构制作多视图与静态体块，继而安排叙事镜头。当前手稿不承诺已完成三维结构、材质工程或实时效果。
